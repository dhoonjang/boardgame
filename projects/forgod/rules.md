## 0. 용어집

이 문서에서 쓰는 용어는 여기 정의된 것만 쓴다. 정의되지 않은 용어를 쓰게 되면 먼저 여기에 추가한다.

| 용어 | 정의 |
|---|---|
| 플레이어 | 게임에 참여하는 사람. 용사 하나를 조종한다 |
| 용사 | 플레이어의 말. 직업과 상태를 가진다 |
| 직업 | 전사, 도적, 법사 중 하나 |
| 상태 | 신성 또는 타락 |
| 능력치 | 힘, 민첩, 지능 |
| 능력치 주사위 | 각 능력치마다 2개씩 있는 d6. 눈이 곧 값이다 |
| 능력치 값 | 해당 능력치 주사위 2개의 눈 합에, 타락 주사위가 그 능력치에 놓여 있으면 그 눈을 더한 값 |
| 타락 주사위 | 타락 용사가 갖는 d6 1개. 능력치 하나에 놓여 그 값에 더해진다 |
| 레벨 | 힘, 민첩, 지능 값 중 최대. 타락 주사위는 제외한다 |
| 체력 | 용사 또는 몬스터의 남은 생명. 최대 체력을 넘지 않는다 |
| 피해 | 체력을 줄이는 양. "힘 피해"는 공격자의 힘 값만큼의 피해 |
| 처치 | 피해로 대상의 체력을 0 이하로 만드는 것 |
| 사망 | 용사가 처치되어 부활 대기에 들어간 상태 |
| 시체 | 사망한 용사가 있던 칸에 남는 마커. 그 용사의 제물을 보관한다 |
| 타일 / 칸 | 보드의 육각형 한 칸. 종류는 design.md#타일-종류와-수 |
| 인접 | 두 칸의 거리가 1인 것 |
| 거리 | design.md#보드의 계산식으로 구한 두 칸 사이의 칸 수 |
| 직선 | 한 칸에서 6방향 중 한 방향으로 계속 이어지는 칸들 |
| 뒤 칸 | 공격자에서 대상으로 향하는 방향으로 대상 바로 다음 칸 |
| 이동력 | 한 턴 동안 이동에 쓸 수 있는 점수 |
| 강제 이동 | 스킬이나 몬스터 효과로 용사가 옮겨지는 것. 이동력을 쓰지 않고 진입 불가 칸에도 들어갈 수 있다 |
| 몬스터 | 보드에 고정된 7종의 적. design.md#몬스터 |
| 몬스터 정수 | 몬스터에게 피해를 준 만큼 얻는 자원. 능력치 올리기에 쓴다 |
| 제물 | 동그라미 ●, 세모 ▲, 네모 ■ 세 종류의 토큰. 몬스터를 처치하면 나온다 |
| 바치기 | 신전 또는 마왕성에서 제물을 공급처로 되돌리는 것 |
| 계시 | 천사 또는 마왕이 내리는 과제 카드. design.md#계시-카드 |
| 신앙 점수 | 천사 계시로 얻는 점수 |
| 마왕 점수 | 마왕 계시로 얻는 점수 |
| 마검 | 보드 위 한 칸에 놓인 토큰. 타락 용사만 가질 수 있다 |
| 신전 | (0, 0) 타일 |
| 마왕성 | (0, −8) 타일 |
| 마을 | 직업이 붙은 9개 타일 |
| 라운드 | 모든 살아 있는 용사가 턴을 한 번씩 마치고 몬스터 페이즈까지 끝나는 단위 |
| 턴 | 한 용사가 R-4.5의 단계를 진행하는 단위 |
| 몬스터 페이즈 | 라운드 끝에 몬스터가 행동하는 단계 |
| 쿨다운 | 스킬을 다시 쓰기까지 남은 라운드 수 |
| 소모값 | 스킬을 쓸 때 드는 값. 한 턴 합계가 지능 값을 넘을 수 없다 |
| 은신 | 지정 공격의 대상이 되지 않는 상태 |
| 속박 | 다음 턴에 이동할 수 없는 상태 |
| 함정 | 도적이 설치하는 토큰 |
| 분신 | 법사가 놓는 말 |
| 강화 | 법사의 다음 스킬이 강화 효과로 발동하는 상태 |
| 지정 공격 | 대상을 하나 골라서 하는 공격. 기본 공격, 대상이 "용사" 또는 "용사/몬스터"인 스킬, 몬스터 공격 |
| 범위 공격 | 대상을 고르지 않고 칸이나 방향으로 하는 공격. 검기 발사, 무한의 표창, 마력 방출, 메테오 |

## 1. 게임 개요

- **R-1.1** 3~6명이 각자 용사 하나를 조종해, 마왕 승리 또는 천사 승리 조건(15장)이 발동할 때까지 라운드를 반복한다.
- **R-1.2** 게임이 끝나면 발동한 승리 종류에 따라 R-15.2 또는 R-15.4로 승자를 정한다.

## 2. 구성물

- **R-2.1** 구성물의 종류와 수량은 design.md#구성물 표를 따른다.
- **R-2.2** 보드 배치는 assets/board.md를 따른다.

## 3. 셋업

- **R-3.1** 각 플레이어는 직업을 하나 고른다. [TBD Q-20: 같은 직업 중복 허용 여부]
- **R-3.2** 각 플레이어는 능력치 주사위 6개를 모두 눈 1로 놓는다.
- **R-3.3** 각 용사의 최대 체력을 design.md#최대-체력 표의 레벨 2 값으로 두고 현재 체력을 최대 체력과 같게 한다. [TBD Q-1: 표 확정]
- **R-3.4** 각 용사는 신성 상태로 시작하며 타락 주사위, 제물, 몬스터 정수, 신앙 점수, 마왕 점수를 갖지 않는다.
- **R-3.5** 각 용사를 자기 직업의 시작 칸(design.md#주요-위치) 중 하나에 놓되, 같은 직업이 둘이면 서로 다른 칸에 놓는다. [TBD Q-20: 같은 직업 3명 이상]
- **R-3.6** 각 플레이어는 계시 카드를 1장 뽑아 갖는다. [TBD Q-9: 어느 덱에서]
- **R-3.7** 몬스터 7종을 design.md#몬스터 위치에 놓고 체력을 최대로 둔다.
- **R-3.8** 마검을 마검 위치에 둔다. [TBD Q-19: 위치와 비공개 처리]
- **R-3.9** 첫 라운드의 턴 순서를 R-4.3으로 정한다.

## 4. 라운드와 턴 구조

- **R-4.1** 한 라운드는 살아 있는 용사들의 턴을 R-4.2의 순서대로 진행한 뒤 몬스터 페이즈(10장)와 라운드 정리(R-4.9)를 하는 것으로 이루어진다.
- **R-4.2** 둘째 라운드부터 턴 순서는 직전 라운드에서 턴 종료 시 남긴 이동력(R-4.8)이 큰 용사부터다. [TBD Q-3: 동점 처리]
- **R-4.3** 첫 라운드는 도적 용사부터 시작해 자리의 시계 방향으로 진행한다. [TBD Q-3: 도적이 없거나 여럿일 때]
- **R-4.4** 사망 상태인 용사는 턴을 갖지 않는다.
- **R-4.5** 한 턴은 턴 시작 처리(R-4.6) → 이동 단계(5장 R-5.1~R-5.3) → 행동 단계(R-5.4~R-5.10) → 턴 종료 처리(R-4.7) 순서로 진행한다. [TBD Q-4: 이동과 행동을 섞을 수 있는지]
- **R-4.6** 턴 시작 처리는 다음 순서로 한다: (1) 산 또는 호수 위에 있으면 R-6.4로 탈출한다, (2) 속박 상태면 해제하고 이번 턴 이동력을 0으로 한다, (3) 무적 태세가 걸려 있으면 끝낸다, (4) 화염 타일 위에 있으면 R-6.7의 피해를 받는다.
- **R-4.7** 턴 종료 처리는 다음 순서로 한다: (1) 마을 타일 위에 있으면 R-6.2로 회복한다, (2) 남은 이동력을 R-4.8로 기록한다.
- **R-4.8** 턴 종료 시 남은 이동력을 그 용사의 "남긴 이동력"으로 기록하며, 다음 라운드 순서 결정(R-4.2)에만 쓰고 이동에 다시 쓸 수 없다.
- **R-4.9** 라운드 정리는 다음 순서로 한다: (1) 사망한 용사의 부활 대기를 R-9.4로 줄인다, (2) 모든 용사의 스킬 쿨다운을 1씩 줄인다(최소 0), (3) 다음 라운드 순서를 R-4.2로 정한다.

## 5. 용사의 행동

- **R-5.1** 이동 단계를 시작할 때 d6 2개를 굴려 그 합에 민첩 값을 더한 만큼을 이번 턴의 이동력으로 한다.
- **R-5.2** 용사는 이동력이 남아 있는 동안 인접한 칸으로 한 칸씩 이동할 수 있고, 한 칸 진입에는 design.md#타일-종류와-수 표의 이동 비용이 들며, 남은 이동력이 비용보다 작으면 그 칸에 진입할 수 없다.
- **R-5.3** 살아 있는 다른 용사가 있는 칸, 몬스터 칸, 산, 호수에는 이동으로 진입할 수 없다.
- **R-5.4** 기본 공격: 거리 1의 용사 또는 몬스터 하나에게 힘 피해를 준다. [TBD Q-5: 턴당 횟수]
- **R-5.5** 스킬 사용: 7장의 규칙에 따라 자기 직업 스킬을 쓴다.
- **R-5.6** 능력치 올리기: 현재 레벨만큼의 몬스터 정수를 지불하고 능력치 하나를 고른 뒤 R-5.7을 진행한다.
- **R-5.7** 판정 주사위 1개를 굴려, 고른 능력치의 주사위 2개 중 눈이 굴린 값보다 작은 것이 있으면 그중 하나의 눈을 1 올리고, 없으면 아무 일도 일어나지 않으며 지불한 정수는 돌려받지 않는다. [TBD Q-2: 둘 다 작을 때 선택 방식, 턴당 횟수]
- **R-5.8** 능력치 주사위의 눈은 6을 넘을 수 없다.
- **R-5.9** 제물 교환: 8장 R-8.6에 따라 인접한 용사와 제물을 주고받는다.
- **R-5.10** 계시 완료: 11장에 따라 조건을 충족한 계시를 완료한다.

## 6. 보드와 지형

- **R-6.1** 평지, 신전, 마왕성, 화염, 마을의 진입 비용은 3, 늪은 5다 (design.md 표).
- **R-6.2** 턴 종료 시 마을 타일 위에 있는 용사는 그 마을이 자기 직업이면 10, 다른 직업이면 5만큼 체력을 회복하며 최대 체력을 넘지 않는다.
- **R-6.3** 산과 호수에는 강제 이동으로만 들어갈 수 있다.
- **R-6.4** 산 또는 호수 위에서 턴을 시작한 용사는 이동 주사위를 굴리지 않고, 자신에게서 거리가 가장 짧은 진입 가능 칸(R-5.3 기준) 중 하나를 골라 그 칸으로 옮긴 뒤 이번 턴 이동력을 0으로 하고 행동 단계로 넘어간다.
- **R-6.5** 언덕에 진입하면 남은 이동력을 전부 잃는다. [TBD Q-6: 진입에 필요한 최소 이동력]
- **R-6.6** 늪에 진입하려면 이동력 5가 필요하다.
- **R-6.7** 신성 용사가 화염 타일에 진입하거나 화염 타일 위에서 턴을 시작하면 피해 10을 받는다. [TBD Q-22: 통과 시 피해 횟수]
- **R-6.8** 타락 용사는 화염 타일 피해를 받지 않으며, 발록이 사망 상태인 동안에는 아무도 화염 타일 피해를 받지 않는다 (R-10.12).
- **R-6.9** 속박 상태인 용사는 R-4.6 (2)에 따라 다음 턴에 이동하지 못한다. [TBD Q-27: 속박 상세]
- **R-6.10** 타락 용사는 마검을 갖고 있지 않으면 신전에 진입할 수 없다.
- **R-6.11** 타락 용사가 마왕성에 진입하면 마검의 위치를 알게 된다 (R-12.8).
- **R-6.12** 시체가 있는 칸에는 진입할 수 있고, 진입한 용사는 그 시체가 보관한 제물을 전부 가져간다.

## 7. 스킬

- **R-7.1** 용사는 자기 직업의 스킬만 쓸 수 있으며, 스킬의 소모값, 쿨다운, 대상, 효과는 design.md#스킬 표를 따른다.
- **R-7.2** 쿨다운이 0인 스킬만 쓸 수 있고, 쓰는 즉시 그 스킬의 쿨다운을 표의 값으로 둔다.
- **R-7.3** 한 턴에 쓴 스킬들의 소모값 합은 지능 값을 넘을 수 없다.
- **R-7.4** 쿨다운이 0인 스킬은 R-7.3 안에서 같은 턴에 다시 쓸 수 있다. [TBD Q-26: 같은 스킬 반복 사용]
- **R-7.5** "힘 피해", "민첩 피해", "지능 피해"는 사용자의 해당 능력치 값만큼의 피해다.

### 7.1 전사

- **R-7.6** 돌진(S-W1): 거리 2인 용사 또는 몬스터 하나를 고르고, 그 대상에 인접한 칸 중 R-5.3 기준 진입 가능한 칸 하나로 이동력 소모 없이 이동한 뒤, 쿨다운이 1 이상인 자기 스킬 하나를 골라 쿨다운을 1 줄인다. [TBD Q-17: 돌진 자신 포함 여부]
- **R-7.7** 일격 필살(S-W2): 자신의 다음 기본 공격 피해에 힘 값을 더한다. [TBD Q-17: 턴을 넘겨 유지되는지]
- **R-7.8** 던져버리기(S-W3): 인접한 용사 하나를 자신에게서 거리 2 이하인 칸으로 강제 이동시키고, 그 칸이 산이면 대상에게 힘 피해를 준다. [TBD Q-16: 호수]
- **R-7.9** 무적 태세(S-W4): 자신의 다음 턴 시작 처리(R-4.6 (3))까지 자신이 받는 모든 피해를 힘 값만큼 줄이며, 0보다 작아지지 않는다.
- **R-7.10** 검기 발사(S-W5): 자신에게서 한 방향을 골라 그 직선의 첫 3칸에 있는 모든 용사와 몬스터에게 힘 피해를 준다. [TBD Q-17: 산에 막히는지]

### 7.2 도적

- **R-7.11** 독 바르기(S-R1): 자신의 다음 기본 공격 피해에 민첩 값을 더한다. [TBD Q-17: 턴을 넘겨 유지되는지]
- **R-7.12** 그림자 함정(S-R2): 현재 칸에 자기 함정을 놓되 보드 위 자기 함정이 이미 3개면 그중 하나를 골라 제거하고 놓으며, 다른 용사가 그 칸에 진입하면 함정을 제거하고 그 용사에게 설치자의 민첩 피해를 준다. [TBD Q-15: 숨는 주체]
- **R-7.13** 함정은 설치자 자신에게는 발동하지 않는다.
- **R-7.14** 배후 일격(S-R3): 인접한 용사 또는 몬스터 하나를 골라, 그 대상의 뒤 칸이 R-5.3 기준 진입 가능할 때만 쓸 수 있으며, 뒤 칸으로 이동력 소모 없이 이동한 뒤 대상에게 민첩 피해를 준다.
- **R-7.15** 은신(S-R4): 자신이 기본 공격이나 피해를 주는 스킬을 쓰거나 피해를 받을 때까지 지정 공격의 대상이 되지 않으며, 범위 공격의 피해는 받고 그 순간 은신이 풀린다.
- **R-7.16** 무한의 표창(S-R5): 자신에게서 한 방향을 골라 그 직선에서 처음 만나는 용사 또는 몬스터에게 민첩 피해를 주되, 그 대상까지의 거리가 2 이상이면 민첩 값의 2배 피해를 주고, 대상보다 먼저 산을 만나면 아무에게도 피해를 주지 않는다. [TBD Q-17: 호수]

### 7.3 법사

- **R-7.17** 스킬 강화(S-M1): 자신이 다음에 쓰는 스킬 하나가 design.md#법사 표의 "강화 시" 효과로 발동한다.
- **R-7.18** 마법 화살(S-M2): 거리 2 이하의 용사 하나 또는 거리 1의 몬스터 하나에게 지능 피해를 주며, 강화 시 자신의 분신이 있으면 분신의 위치를 기준으로 대상을 고른다. [TBD Q-17: 몬스터 사거리] [TBD Q-23: 분신 기준 사거리]
- **R-7.19** 분신(S-M3): 현재 칸에 자기 분신을 놓으며, 분신은 지능 값 이상의 피해를 한 번 받으면 사라지고, 강화 시에는 분신을 놓는 대신 자신과 분신의 위치를 맞바꾼다. [TBD Q-23: 대상 지정 가능 여부, 재사용 시 기존 분신]
- **R-7.20** 마력 방출(S-M4): 자신과 거리 1인 모든 용사와 몬스터에게 지능 피해를 주며, 강화 시 피해를 입은 용사를 자신에게서 멀어지는 방향으로 1칸 강제 이동시킨다.
- **R-7.21** 메테오(S-M5): 타일 하나를 골라 그 위의 용사 또는 몬스터에게 지능 피해를 주며, 강화 시 지능 값의 2배 피해를 준다. [TBD Q-17: 사거리]
- **R-7.22** 리치의 효과(R-10.10)가 걸린 라운드에는 메테오가 몬스터에게 피해를 주지 않는다.

## 8. 몬스터 정수와 제물

- **R-8.1** 용사가 몬스터에게 피해를 주면 실제로 줄어든 체력만큼 몬스터 정수를 얻는다.
- **R-8.2** 몬스터 정수는 R-5.6에만 쓴다.
- **R-8.3** 몬스터가 처치되면 design.md#몬스터 표의 드롭 제물이 나오고, 마지막 피해를 준 용사가 종류별로 절반(홀수면 버림)을 먼저 가져간다.
- **R-8.4** R-8.3의 나머지는 처치된 몬스터에 인접한 용사들이 인접 칸 번호(design.md#몬스터-인접-칸-번호)가 큰 순서로 돌아가며 하나씩 가져간다. [TBD Q-12: 종류 선택, 인접 용사가 없을 때, 마지막 공격자 포함 여부]
- **R-8.5** 용사는 제물을 몇 개든 가질 수 있다.
- **R-8.6** 인접한 두 용사는 서로 합의하면 제물을 어떤 조합으로든 주고받을 수 있다. [TBD Q-13: 시점]
- **R-8.7** 제물을 주고받은 두 용사는 그 사실을 게임이 끝날 때까지 기억해야 하며, 마왕 계시 M-7의 판정에 쓴다.
- **R-8.8** 사망한 용사의 제물은 시체에 남고 R-6.12로 가져갈 수 있다.

## 9. 체력, 사망, 부활

- **R-9.1** 용사의 최대 체력은 직업과 레벨에 따라 design.md#최대-체력 표로 정해지며, 레벨이 올라 최대 체력이 오르면 현재 체력도 상승분만큼 오른다. [TBD Q-1]
- **R-9.2** 체력이 0 이하가 된 용사는 즉시 사망하며, 그 칸에 시체를 놓고 용사 말을 치운다.
- **R-9.3** 사망한 용사는 능력치, 타락 주사위, 몬스터 정수, 점수, 계시 카드를 유지하고 제물만 시체에 남긴다.
- **R-9.4** 사망한 용사는 사망한 라운드를 제외하고 2라운드 동안 턴을 갖지 않으며, 그다음 라운드 시작 시 부활한다.
- **R-9.5** 부활하는 용사는 자기 직업 시작 칸 중 빈 칸 하나에 놓이고, 계시 카드 1장을 뽑으며, 타락 상태였다면 신성으로 돌아갈지 선택한다 (R-12.7). [TBD Q-14: 체력, 쿨다운, 버프]
- **R-9.6** 부활 시 시작 칸이 모두 차 있으면 시작 칸에 인접한 빈 칸 중 하나를 고른다.

## 10. 몬스터 페이즈

- **R-10.1** 몬스터 페이즈는 모든 살아 있는 용사의 턴이 끝난 뒤 시작한다.
- **R-10.2** d6 6개를 굴려 오름차순으로 늘어놓고 1번부터 6번 자리로 삼는다.
- **R-10.3** 몬스터마다 design.md#몬스터 표의 자리에 놓인 눈의 합을 구하고, 사망한 몬스터는 이번 페이즈에 행동하지 않는다. [TBD Q-30: 몬스터 행동 순서]
- **R-10.4** 각 몬스터는 효과(R-10.9 이하) → 공격(R-10.5) 순서로 처리한다.
- **R-10.5** 공격 대상 칸 번호는 합을 그 몬스터의 인접 칸 수로 나눈 나머지이며, 그 칸에 용사가 있으면 그 용사가 대상이고, 없으면 인접 칸 중 용사가 있는 가장 작은 번호 칸의 용사가 대상이며, 인접 칸에 용사가 없으면 공격하지 않는다.
- **R-10.6** 은신 상태인 용사는 R-10.5의 대상 선정에서 없는 것으로 취급한다.
- **R-10.7** 대상 용사는 합만큼 피해를 받는다.
- **R-10.8** 트롤은 대상이 타락 용사이고 합이 짝수이면 공격하지 않는다.
- **R-10.9** 하피는 합이 7 이상이면 공격 전에 인접한 모든 용사를 하피에서 멀어지는 방향으로 1칸 강제 이동시킨다. [TBD Q-31: 목적지가 막힌 경우]
- **R-10.10** 리치는 합이 15 이상이면 다음 몬스터 페이즈까지 모든 몬스터가 메테오 피해를 받지 않고, 히드라는 합이 15 이상이면 잃은 체력의 2배를 회복하며, 골렘은 합이 12이면 다음 몬스터 페이즈까지 기본 공격 피해를 받지 않는다. [TBD Q-18: 히드라 최대 체력 초과]
- **R-10.11** 그린딜로는 합이 7 이상이고 R-10.7의 피해를 준 경우 그 용사를 속박 상태로 만든다. [TBD Q-27]
- **R-10.12** 발록이 처치되면 화염 타일이 피해를 주지 않으며(R-6.8), 발록이 부활하면 다시 피해를 준다.
- **R-10.13** 사망한 몬스터는 자기 합이 정해진 값 이상이면 부활하고 다음 라운드부터 행동한다. [TBD Q-7: 몬스터별 값, 대상 몬스터, 부활 체력]
- **R-10.14** 몬스터에게 준 피해가 남은 체력을 넘으면 넘는 만큼은 정수로 얻지 않는다 (R-8.1).

## 11. 계시

- **R-11.1** 계시 카드는 천사 계시와 마왕 계시로 나뉘며 목록은 design.md#계시-카드 표를 따른다. [TBD Q-9: 덱 구성]
- **R-11.2** 플레이어는 가진 계시 카드를 손에 둔다. [TBD Q-10: 비공개 여부]
- **R-11.3** 계시의 수행 조건을 충족하면 그 계시를 완료하고 보상을 적용한 뒤 카드를 완료 더미에 둔다. [TBD Q-11: 자동인지 선언인지]
- **R-11.4** 제물을 바치는 계시는 용사가 신전(천사) 또는 마왕성(마왕) 타일 위에 있는 동안 바친 제물을 공급처로 돌려주며 완료한다. [TBD Q-11: 시점]
- **R-11.5** 공격이나 처치를 조건으로 하는 계시는 그 공격 또는 처치가 일어난 순간 판정한다.
- **R-11.6** 보상 "계시 카드 n장"은 즉시 n장을 뽑는 것이다. [TBD Q-9: 어느 덱]
- **R-11.7** 보상 "바친 수만큼"은 그 계시를 완료하며 바친 해당 종류 제물의 개수와 같은 점수다.
- **R-11.8** 보상 "타락 주사위 +n"은 R-12.3에 따라 타락 주사위 눈을 n 올리는 것이며, "타락 주사위 n으로 시작"은 타락하면서 눈을 n으로 두는 것이다. [TBD Q-29: 신성 용사가 받았을 때]
- **R-11.9** A-7 천사의 가호는 타락 용사의 공격으로 받을 피해가 현재 체력 이상일 때 발동하며, 그 피해를 받지 않고 체력을 최대로 회복한 뒤 보상을 적용한다.
- **R-11.10** 타락 용사는 천사 계시를 완료할 수 없고, 신성 용사는 마왕 계시를 완료할 수 없되, M-4와 M-9처럼 수행 조건에 "신성 상태로"가 붙은 마왕 계시는 신성 용사만 완료할 수 있다.
- **R-11.11** 보상 "게임 종료"가 적용되면 15장의 천사 승리가 발동한다.

## 12. 신성과 타락, 마검

- **R-12.1** 신성 용사가 다른 용사를 처치하면, 처치된 용사가 신성이었다면 처치자는 즉시 타락하고, 처치된 용사가 타락이었다면 처치자는 타락할지 선택한다.
- **R-12.2** 타락하는 용사는 타락 주사위를 눈 1로 받아 힘, 민첩, 지능 중 하나에 놓는다.
- **R-12.3** 타락 용사가 다른 용사를 처치하면 타락 주사위 눈을 1 올리며, 눈은 6을 넘지 않는다.
- **R-12.4** 타락 주사위를 놓은 능력치는 유지된다. [TBD Q-25: 변경 가능 여부]
- **R-12.5** 타락 용사는 신전에 진입할 수 없고(R-6.10), 화염 피해를 받지 않으며(R-6.8), 마검을 뽑을 수 있다(R-12.9).
- **R-12.6** 신성 용사는 마검을 뽑을 수 없다.
- **R-12.7** 타락 용사는 부활할 때만 신성으로 돌아갈 수 있으며, 돌아가면 타락 주사위를 잃는다.
- **R-12.8** 타락 용사가 마왕성에 진입하면 마검의 위치를 알게 된다. [TBD Q-19]
- **R-12.9** 마검 위치를 아는 타락 용사가 마검 칸에 있으면 마검을 가져갈 수 있고, 가져가면 보드에서 마검이 사라진다.
- **R-12.10** 마검을 가진 타락 용사는 신전에 진입할 수 있다. [TBD Q-8: 몬스터와의 상호 공격 불가 채택 여부]
- **R-12.11** 마검을 가진 용사가 사망하면 마검은 시체에 남고 R-6.12로 가져갈 수 있되 타락 용사만 가져갈 수 있다.

## 13. 우선순위와 타이밍

- **R-13.1** 규칙이 충돌하면 카드에 인쇄된 텍스트가 이 문서보다 우선하고, 이 문서 안에서는 번호가 큰 섹션의 구체 규칙이 번호가 작은 섹션의 일반 규칙보다 우선한다.
- **R-13.2** 한 번의 피해로 여러 판정이 동시에 걸리면 피해 감소(R-7.9) → 은신 해제(R-7.15) → 천사의 가호(R-11.9) → 체력 감소 → 사망(R-9.2) → 타락(R-12.1) → 계시 판정(R-11.5) 순서로 처리한다.
- **R-13.3** 강제 이동으로 함정 칸에 들어가도 함정은 발동한다.
- **R-13.4** 강제 이동으로 화염 타일에 들어가면 R-6.7의 진입 피해를 받는다.
- **R-13.5** 마왕 승리(R-15.1)와 천사 승리(R-15.3)가 같은 순간 발동하면 먼저 조건을 충족한 쪽이 이기고, 판정 순서는 R-13.2를 따른다.

## 14. 규칙에 없는 상황

- **R-14.1** 이 문서가 답하지 않는 상황이 발생하면 그 상황을 open-questions.md에 등록하고, 이번 게임에서는 현재 턴 플레이어가 아닌 플레이어들의 다수결로 처리한다.

## 15. 게임 종료와 승자 결정

- **R-15.1** 마왕 승리: 마검을 가진 타락 용사가 신전에 진입하는 순간 게임이 끝난다.
- **R-15.2** 마왕 승리 시 (마왕 점수 − 신앙 점수)가 가장 큰 플레이어가 이긴다.
- **R-15.3** 천사 승리: 신성 용사가 보상에 "게임 종료"가 있는 천사 계시(A-6, A-8)를 완료하는 순간 게임이 끝난다.
- **R-15.4** 천사 승리 시 (신앙 점수 − 마왕 점수)가 가장 큰 플레이어가 이긴다.
- **R-15.5** 승자는 게임을 끝낸 플레이어와 다를 수 있다.
- **R-15.6** 점수 차가 같은 플레이어가 둘 이상이면 공동 승리다. [TBD Q-21]
