# 패스 앤 슛 미결 사항

- 형식: `- [ ] **Q-n** 질문 — 관련: R-x.y, design.md#섹션`
- 해결되면 `[x]`로 바꾸고 끝에 `→ D-n`을 붙인다. 항목을 지우지 않는다.
- rules.md의 `[TBD Q-n]` 마커와 대응한다. 마커가 가리키는 Q는 반드시 열려 있어야 한다.
- status가 `final`이 되려면 `[ ]` 항목이 0개여야 한다.
- 각 Q 의 제안안은 `assets/proposal-roles-and-rules-2026-09-06.md` 에 있다.

- [x] **Q-24** 역할 20종의 밸런스를 어떻게 맞출 것인가? — 관련: design.md#역할, Q-14, Q-21 → D-3
  - 후보: (a) 파워 버짓 2점 규칙 + 조정안 v2 (아래) (b) 템포형만 손보기 (박투박·윙어·윙백) (c) 현행 유지하고 사람 플레이테스트 3판 후 재검토
  - 파워 버짓 안: 무조건 이동력 +1 = 2점, 조건부 이동력 +1 = 1점, 조작 절약(이동+슛 같은 더블 액션) = 2점, 조작 없는 이동(조건부) = 1점, 판정 ±2 한 종류 = 1점, 골 직결 판정(슛 보정 ±2) = 2점, 사거리 +2 = 1점, 대가(판정 -1 또는 이동력 -1) = -1점. 역할당 합계 2점.
  - 조정안 v2: 박투박 = 조작되지 않은 턴에만 1칸 (또는 이동력 3 으로 치환) / 윙어 = 이동력 3 + 크로스 +2, 태클 -1 (슛 사거리 +1 삭제) / 윙백 = 터치라인 열에서 이동력 +1, 크로스 +1 / 풀백 = 터치라인 열에서 태클 +2, 인접 상대의 크로스 -2 / 타겟맨 = 이동력 2, 수신 +2, 레이오프 / 맨마커 = 상대 이동 거리만큼(최대 2칸) 따라감 / 드리블러 = 공을 가졌을 때 이동력 3, 태클당할 때 -1 / 스토퍼 = 태클 +2, 파울 면제 / 스위퍼 키퍼 = 이동력 2, PA 밖 이동·태클 (패스 +2 삭제) / 레지스타 = 사거리 +2, 자기 진영 +2 / 나머지 유지
  - 공통 규칙 후보: 조작 없는 이동은 팀당 턴에 1회 (박투박·폴스 나인·플레이메이커·섀도잉 중첩 방지)
  - 맥락: 정적 분석에서 판정 +2 는 한 판에 3~5회 굴림 × 10%p 라 0.5회 차이인데, 박투박의 공짜 1칸은 판당 24칸 = 조작 12회 = 팀 조작 예산의 25%. 템포형 > 더블 액션형 > 판정형 순으로 크다. 봇 실험(playtests/2026-09-07-role-value-sim.md)은 템포를 못 살려 이 차이를 못 본다
- [x] **Q-25** 카드 게임의 핵심 루프는 무엇인가? — 관련: concept.md#핵심 메커닉 → D-8 (2+2 국면 대결형)
