# 패스 앤 슛 현황판

> 한 줄 소개: 두 감독이 역할이 다른 선수 칩 20개 중 11명을 육각 경기장에 배치하고, 정해진 턴 동안 이동·패스·슛·태클을 20면체로 판정해 골을 더 넣는 1:1 체스류 축구 게임.

## 현재 상태

- status: `idea` (라이프사이클과 진입 조건은 루트 CLAUDE.md 참고)
- 다음 단계(`draft`) 진입에 부족한 것: concept.md 는 채웠으나 핵심 경험(Q-16)·시간·연령(Q-15) 확인 필요. rules.md, design.md 는 템플릿 상태.

## 핵심 결정 요약

decisions.md의 핵심만 3~7줄로 요약한다. 상세는 decisions.md.

- D-1: 2인 체스류. 팀별 역할 칩 20개(GK 2 / DF 7 / MF 6 / FW 5) 중 선발 11명을 육각 보드에 배치.
- D-1: 전반 N턴 + 후반 N턴. 킥오프 소유권은 팀별 교대.
- D-1: 자기 턴에 선수 2명 조작. 이동 / 패스 / 슛 / 태클. 패스·슛·태클은 20면체로 판정.
- D-1: 역할마다 규칙상 이점. 예시 3종(인사이드 포워드, 드리블러, 박투박)은 Q-14 에서 확정.
- D-3: 역할 밸런스 v2. 템포형(박투박·윙어·윙백)에 조건, 약체(타겟맨·맨마커·드리블러·풀백) 강화, 조작 없는 이동은 팀당 턴 1회.
- D-2: 아웃볼 없음. 슛 근소 실패는 코너킥(다음 턴 시작 시 조작 없이 크로스). 태클 실패 중 주사위 1~3 은 파울 → 프리킥, PA 안이면 PK.

## 이 프로젝트 작업 시 주의

- 규칙을 바꾸면 rules.md 반영 → decisions.md 기록 → 관련 Q 닫기 순서로 진행한다.
- 제안 문서(assets/proposal-*.md)의 수치는 원본이 아니다. 사용자가 확정한 것만 design.md 로 옮기고, rules.md 는 design.md 표를 가리킨다.
- 목업(playtests/mock.html)의 엔진은 제안 문서 1~2 절을 그대로 구현한 것이다. 규칙이 확정되면 목업도 같이 고친다.
- 역할 이점은 "이동력 / 추가 조작 / 판정 보정 / 사거리 / 위치 조건" 다섯 가지 원시 규칙만 조합한다. 새 원시 규칙이 필요하면 D-n 으로 남긴다.
