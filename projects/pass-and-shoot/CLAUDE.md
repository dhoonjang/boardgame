## 핵심 결정 요약

decisions.md의 핵심만 3~7줄로 요약한다. 상세는 decisions.md.

- D-19: 드래프트 폐지. 플레이는 공격·수비 공용 덱에서 3장씩 뽑아 손에 들고, 낸 카드는 버린 더미, 판정 뒤 1장 뽑기, 교체 뽑기 하프 2회. 시스템은 뒷면 4장씩 그대로.
- D-18: 카드마다 고유 효과 한 줄(40장 전부). 겹침은 단계 순서(아이콘 → 맞대기 → 마커 → 결과 → 이동 → 도착, 수비 먼저 공격 나중). 판정 엔진 playtests/engine-v5.js 를 평가기·웹 게임이 공유.
- D-17: 카드 종류. 시스템(8+8, 뒷면 4장씩, 세워 두고 교체하면 그 라운드 마커 1칸 손해) / 플레이(12+12, 라운드마다 1장 동시 공개). 전·후반 9 라운드. 배분·손패·공유판은 D-19 로 대체.
- D-16: 혼선 벌점 폐지(반대 성향은 1:1 로 지우기만). 기본 마커 4/8/12/16.
- D-15: 요구 조건 재정의. 등급 없음, 카드 value 편차폭 ≤ 5, 카운터 존재, 조합 value 15~85, 무작위 18라운드 기대 골 2~4, 축구 타당성. 효과 연쇄 허용.
- D-14: 마커는 1~19 의 서로 다른 칸에 순서대로(겹침 없음). 다섯 결과 모두 최소 1/20. 끊기는 ④ 를 19 로. 1점 = 1칸.
- D-13: 효과 정리(주사위 두 번 굴리기 없음). 효과 종류 구분은 D-18 로 대체.
- D-12: 판정 v5. 공유 위치 트랙 −2~2(2 초과 = 골, 슈팅 굴림 없음), 다섯 결과(카운터·소유 상실·교착·전진·돌파), 마커는 특성마다 2개를 합쳐서 한 번에 옮기고 닿으면 밀기, 맞대기 −d/+a.
- D-11: 카드 아이콘 체계. 같은 특성의 두 성향은 반대 방향 아이콘(상쇄가 보이게), 수비는 특성 색 방패 안에 노리는 성향(카운터), 수비 이름은 코칭 용어(압박·내려서기·대인·지역 커버·측면 봉쇄·중앙 밀집·딥 라인·하이 라인).
- D-10: 판정 v4. 저지 아이콘, 2개 미만은 없는 것, 호흡·보너스 없음. 맞대기 공식·마커 규칙은 D-12 로, 혼선은 D-16 으로 대체.
- D-9: 카드 구조 v2 확정(성향 토큰 4특성, 상쇄·혼선, d20 밴드 트랙). 맞대기 표는 D-10 으로 대체.
- D-8: 선수 카드 없음. 라운드마다 2장씩(수비 1 → 공격 1 → 동시 1씩), 2+2 상성 판정. 기본 카드 공용·상시, 특수 카드는 뽑은 쪽만 갖고 사용 후 공유.
- D-7: 핵심 경험 = 실제 축구의 전술적 고민. 전술 요소는 카드로 추상화. 규칙마다 실제 축구의 어떤 고민에 대응하는지 말할 수 있어야 한다.
- D-6: 체스류(육각 보드, 역할 칩 20개, 조작 2명, d20 판정) 폐기. 카드 게임 형태로 재기획. 2인 축구와 이름은 유지.
- D-1~D-5 는 폐기된 체스류 안의 기록. 역할 20종 아이디어만 선수 카드 후보로 살아 있다 (Q-14).
