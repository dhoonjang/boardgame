# 패스 앤 슛: 역할 아이디에이션과 규칙 골격 (제안, 2026-09-06)

**상태: 폐기 (D-6, 2026-09-07). 체스류 안의 기록으로만 보존한다.** 원래 상태: 제안. 사용자가 확정한 것은 concept.md 와 decisions.md D-1 뿐이다. 이 문서의 수치와 역할 이점은 전부 가안이며, 사용자가 고른 것만 design.md 와 rules.md 로 옮긴다. 각 결정 지점은 open-questions.md 의 Q 번호로 가리킨다.

## 0. 확정된 뼈대 (D-1)

1. 2인 1:1 체스류.
2. 팀별 역할 칩 20개: GK 2 / DF 7 / MF 6 / FW 5. 선발 11명.
3. 육각 칸 경기장.
4. 전반 N턴 + 후반 N턴. 킥오프 소유권은 팀별 교대.
5. 한 턴 = 각 팀이 자기 턴을 하나씩 수행.
6. 자기 턴에 선수 2명 조작. 이동 / (공 소유 시) 패스·슛 / (공 소유 상대와 인접 시) 태클.
7. 패스·슛·태클은 d20 판정. 결과로 소유권 또는 골이 정해진다.

## 1. 규칙 골격 (제안)

### 1.1 용어 (제안)

| 용어 | 뜻 |
|---|---|
| 라운드 | D-1 의 "하나의 턴". 두 팀이 자기 턴을 한 번씩 수행하면 1라운드. N 은 라운드 수로 센다 (Q-2) |
| 턴 | 한 팀이 선수 2명을 조작하는 단위 |
| 조작 | 선수 1명에게 액션 1개를 시키는 것. 턴당 2회 |
| 액션 | 이동, 패스, 슛, 태클 중 하나 |
| 소유 | 공 토큰이 놓인 칸의 선수가 공을 가진 상태 |
| 루스볼 | 공 토큰이 있으나 아무도 소유하지 않은 상태 (Q-17) |
| 인접 | 육각 칸에서 변을 맞댄 6칸 |
| 거리 | 두 칸 사이의 최단 칸 수 (육각 거리) |
| 골 칸 | 각 골 행 가운데의 2칸 (골 에어리어). 슛 거리는 가장 가까운 골 칸까지의 거리 |
| 페널티 에어리어(PA) | 자기 골 행 포함 3행, 폭 4~5칸의 상자 (D-5) |
| 터치라인 열 | 각 행의 양 끝 칸 |
| 자기 진영 | 센터 행을 포함해 자기 골 쪽 절반 |
| 판정 | d20 을 굴려 보정을 더한 값이 목표값 이상이면 성공 |

### 1.2 보드 (D-5 로 기하 확정, 행 수는 Q-1)

- 15행. 홀수 행 9칸(열 0~8), 짝수 행 8칸(열 0~7, 오른쪽으로 반 칸 밀림)이 번갈아 놓여 좌우 대칭. 센터 칸 (4,7) 이 정중앙이고 킥오프 지점이다. 총 127칸.
- 골 칸(골 에어리어): 골 행(0행, 14행)의 가운데 2칸(열 3, 4). 골은 보드 밖이며 슛이 성공하면 공이 골로 들어간 것으로 본다.
- PA: 골 행 포함 3행, 폭은 9칸 행 열 2~6, 8칸 행 열 2~5 (13칸). 센터 서클: 센터 칸과 인접 6칸. 터치라인 열: 각 행의 양 끝 칸.
- 실제 규격 대비: PA 폭 40.3/68 ≈ 5.3칸, 깊이 16.5/105 ≈ 2.4행, 서클 반지름 9.15/68 ≈ 1.2칸. 센터에서 골 칸까지 거리 7 이라 "롱패스 한 번 + 슛 한 번" 이 한 턴에 성립한다.

### 1.4 셋업 (Q-7, Q-8, Q-13)

1. 각자 20개 칩에서 선발 11명을 고른다. GK 1명 필수. 나머지 포지션 구성은 자유.
2. 전반 킥오프 팀을 정한다 (동전 또는 d20 높은 쪽).
3. 킥오프 팀부터 한 명씩 번갈아 자기 진영에 배치한다 (순서는 Q-7). GK 는 자기 골 칸 중 하나. 양 팀 모두 중앙선(센터 행)과 센터 서클(센터 칸에서 거리 2 이내)에는 들어갈 수 없다. 예외는 킥오프 팀 선수 1명이 센터 칸에 공과 함께 서는 것뿐이다 (D-4).
4. 배치가 끝나면 킥오프 팀의 턴부터 라운드 1 을 시작한다.

### 1.5 라운드와 턴 (Q-2, Q-6)

- 라운드마다 킥오프 팀이 먼저, 상대가 나중에 턴을 한다. 이 순서는 하프 내내 고정.
- 턴: 서로 다른 선수 2명을 골라 각각 액션 1개. 조작 순서는 자유. 2명 모두 조작하지 않아도 된다.
- 역할 이점의 "조작 없이" 이동은 조작 2회에 포함되지 않는다.
- 후반: 라운드 N 이 끝나면 하프타임. 교체(Q-8) 후 킥오프 배치로 리셋하고, 전반에 킥오프하지 않은 팀이 킥오프한다.

### 1.6 액션

**이동**: 이동력 이하의 칸 수만큼 인접 칸을 따라 움직인다. 선수가 있는 칸은 통과할 수 없고 멈출 수도 없다. 공을 가진 선수가 이동하면 공도 함께 간다(드리블).

**패스** (공 소유 선수만): 패스 사거리 이내의 아군 1명을 목표로 판정. 거리 1~3 은 숏패스, 4 이상은 롱패스. 숏패스이고 길목(두 선수 사이 최단 경로에 놓일 수 있는 칸)에 상대가 없고 수신자에 인접한 상대도 없으면 판정 없이 성공한다 (D-5). 경로에 선수가 있어도 상관없다 (Q-3, 가안 (a)). 성공하면 공은 목표 선수에게. 실패는 Q-17: 목표 선수에 인접한 상대가 있으면 그 상대 중 상대가 고른 1명이 공을 가진다(인터셉트). 인접한 상대가 없으면 공은 목표 선수 칸에 루스볼로 놓이고, 그 선수가 소유하려면 조작 1회(트래핑)가 필요하다.

**슛** (공 소유 선수만, 슛 사거리 이내): 골 칸까지의 거리로 목표값을 정해 판정. 성공하면 골. 근소 실패는 코너킥, 그 외 실패는 상대 GK 소유 (1.11 절, D-2).

**태클** (공 소유 상대와 인접한 선수만): 판정 성공 시 공이 태클한 선수에게 오고, 그 턴이 끝난 뒤 같은 팀이 이어서 한 번 더 턴을 한다 (보너스 턴, D-5. 보너스 턴 안의 태클은 또 보너스를 주지 않는다). 실패 시 아무 일도 없다. 단, 실패 중 주사위 1~3 은 파울이다 (1.11 절, D-2).

**트래핑** (루스볼이 놓인 칸의 선수만): 조작 1회로 소유. 판정 없음.

### 1.7 판정표 (Q-4, Q-18)

d20 + 보정 합계 ≥ 목표값이면 성공. 주사위 1 은 항상 실패, 20 은 항상 성공. 보정 합계는 -5~+5 로 자른다 (가안).

| 판정 | 목표값 | 기본 성공률 |
|---|---|---|
| 숏패스 (거리 1~3) | 6+ | 75% |
| 롱패스 (거리 4~사거리) | 11+ | 50% |
| 슛, 거리 0~2 | 10+ | 55% |
| 슛, 거리 3~4 | 14+ | 35% |
| 슛, 거리 5 | 18+ | 15% |
| 태클 | 11+ | 50% |

| 보정 | 값 |
|---|---|
| 패스 목표 선수에 인접한 상대 1명당 | -2 |
| 슈터에 인접한 상대 1명당 | -1 |
| 상대 GK 가 자기 PA 안에 있으면 | -2 |
| 태클: 포지션 기본치 | DF +1, MF 0, FW -1, GK 0 |
| 역할 이점 | 2 절 표 |

기대치 계산 예: 숏패스로 PA 안 포처에게 연결(마킹 1명, 8+, 65%) 후 거리 2 슛(포처 +3, GK -2, 인접 상대 1명 -1 → 10+, 55%). 한 번의 공격 시퀀스에서 골 확률 약 36%. 경기당 5~6번 시퀀스가 나오면 팀당 2골 안팎. 이 숫자를 목표로 삼을지가 Q-4 의 핵심.

### 1.8 공 소유권 정리표

| 상황 | 결과 |
|---|---|
| 패스 성공 | 목표 선수 소유 |
| 패스 실패, 목표 선수에 인접 상대 있음 | 상대가 고른 인접 상대 선수 소유 |
| 패스 실패, 인접 상대 없음 | 목표 선수 칸에 루스볼 |
| 슛 성공 | 골. 1.9 절 재개 |
| 슛 실패 | 상대 GK 소유 |
| 태클 성공 | 태클한 선수 소유 |
| 태클 실패 | 변화 없음 |
| 루스볼 칸의 선수가 트래핑 | 그 선수 소유 |

### 1.9 득점 후 재개, 하프타임, 종료 (Q-9, Q-10)

- 골 후: 양 팀이 킥오프 배치로 돌아가고 실점 팀이 킥오프한다 (가안 (a)). 라운드 수는 계속 센다. 라운드 안의 턴 순서는 바뀌지 않는다.
- 하프타임: 1.5 절.
- 종료: 후반 라운드 N 의 두 번째 턴이 끝나면 종료. 골이 많은 팀 승. 동점은 Q-9. 가안: PK 5개씩, 슛 거리 2 판정(10+)에 GK -2 만 적용, 역할 보정은 적용.

### 1.10 규칙에 없는 상황 폴백 (제안)

규칙서가 답을 주지 않는 상황이 나오면, 그 시점에 공을 소유하지 않은 팀이 두 해석 중 하나를 고른다. 루스볼이면 마지막으로 소유했던 팀의 상대가 고른다. 고른 해석은 그 경기 동안 유지하고, 경기 후 Q 로 등록한다.

### 1.11 세트피스 (D-2 로 확정, 2026-09-06)

- 아웃볼·스로인 없음. 판 가장자리는 벽.
- 코너킥: 슛 근소 실패(주사위 + 보정 ≥ 목표값 - 3, 주사위 1 제외) → 슈터 쪽 코너 칸에 공. 공격 팀의 다음 턴 시작 시 조작 없이 사거리 6 이내 아군에게 크로스 판정(롱패스 목표값, 수신자 마킹 -2/명, 타겟맨 +3, 에어리얼 수신 +2·인접 -2). 하프 종료 시 소멸.
- 파울: 태클 실패 중 주사위 1~3. 프리킥 = 파울당한 선수가 그 자리에서 조작 없이 패스 또는 슛 1회(키커 인접 보정 무시), 또는 어드밴티지. 태클한 팀의 PA 안이면 PK(필드 플레이어 키커, 슛 거리 2 목표값, GK 보정과 키커 역할 보정만).
- 상세와 근거는 decisions.md D-2.

## 2. 역할 20종 (제안, Q-14)

### 설계 원칙

- 역할 이점은 다섯 가지 원시 규칙만 조합한다: **이동력**, **추가 조작**(조작 없이 하는 행동 또는 한 조작에 두 행동), **판정 보정**, **사거리**, **위치 조건**(인접, 터치라인 열, PA, 자기 진영).
- 역할당 이점은 1개, 많아야 2개. 문장 하나로 끝나야 한다.
- 포지션 기본치(1.3 절)가 뼈대, 역할은 예외. 그래서 같은 포지션끼리는 이점만 다르다.
- 강한 역할에는 대가를 붙인다 (윙어의 태클 -1 처럼).
- 사용자 예시 3종은 그대로 넣었다.

### 공통 규칙 (D-3)

- 조작 없는 이동(박투박, 폴스 나인 연계, 플레이메이커 연계, 섀도잉)은 팀당 턴에 1회만 일어난다.
- 파워 버짓: 역할당 2점. 무조건 이동력 +1 = 2점, 조건부 이동력 +1 = 1점, 더블 액션 = 2점, 조건부 공짜 이동 = 1점, 판정 ±2 한 종류 = 1점, 골 직결 판정(슛 ±2) = 2점, 사거리 +2 = 1점, 대가 = -1점.
- v1(2026-09-06 초안)은 decisions.md D-3 의 변경 목록으로 복원할 수 있고, 목업에서는 설정 "역할 세트 v2" 를 끄면 v1 로 돈다.

### 역할 간 상호작용 (밸런스 확인 포인트)

- 레지스타 → 타겟맨 롱패스: 11+ 에 레지스타 +2, 타겟맨 +3 이면 6+ (75%). 마킹 1명(-2)이 붙어도 8+. 너무 쉬우면 타겟맨 +3 을 +2 로.
- 플레이메이커 → 포처: 패스 성공 시 포처가 1칸 이동해 PA 진입, 다음 조작으로 슛 +3. "패스 한 번, 슛 한 번" 의 정석 콤보.
- 맨마커 vs 드리블러: 드리블러가 인접을 이용해 3칸 가도 맨마커가 1칸 따라붙는다. 드리블러는 인접하지 않은 경로를 골라야 한다.
- 볼 위너 vs 레지스타: 볼 위너가 인접하면 레지스타의 자기 진영 +2 가 +1 로 줄고 태클 위협도 받는다.
- 윙백 + 윙어 같은 측면: 둘 다 이동력 3 이라 한 턴에 6칸 전진이 가능하다. 반대편 풀백이 터치라인 열에서 태클 +2 로 받아친다.
- 리베로 + 슛 스토퍼: PA 안 슛이 -5 (상한). 포처 +3 이라도 거리 2 슛이 12+. 수비 몰빵 구성의 상한을 여기서 정한다.

### 예비 아이디어 (교체 후보)

- 프레싱 포워드: 인접한 상대의 패스 판정 -2. (볼 위너의 FW 판)
- 스피드스터: 이동력 4. 태클 -2. 슛 사거리 4.
- 라인 리더: 오프사이드(Q-12)가 있을 때만 의미. 자기와 같은 행 이하의 상대 FW 는 패스 목표가 될 수 없다.
- 세트피스 전문가: 파울(Q-5)이 있을 때만 의미. 프리킥·PK 판정 +3.
- 캡틴: 경기당 1회 판정 재굴림. (모든 포지션에 붙일 수 있는 부가 태그로 쓰는 안)
- 엔포서: 태클 +3, 단 주사위 1~3 이면 파울. (Q-5 채택 시)

## 3. 시나리오

가안 수치(1 절)와 역할(2 절)로 진행한 예. 좌표 대신 거리로 적는다. A 팀 킥오프, 두 팀 모두 4-3-3, N=12.

### 3.1 선발 구성 예

- A 팀: 스위퍼 키퍼 / 풀백, 스토퍼, 에어리얼 센터백, 윙백 / 레지스타, 박투박, 플레이메이커 / 윙어, 폴스 나인, 포처
- B 팀: 슛 스토퍼 / 풀백, 스토퍼, 리베로, 맨마커 / 볼 위너, 메짤라, 박투박 / 윙어, 타겟맨, 인사이드 포워드

### 3.2 라운드 1

**A 턴.** 조작 1: 센터 칸의 폴스 나인(공)이 거리 2 뒤의 레지스타에게 숏패스. 목표 6+, 마킹 없음. d20 = 13, 성공. 폴스 나인 이점은 "이동한 뒤" 라 여기선 발동하지 않는다. 조작 2: 윙어가 터치라인 열을 따라 3칸 전진. 박투박의 공짜 1칸으로 중앙으로 한 칸.

**B 턴.** 조작 1: 볼 위너가 2칸 이동해 레지스타에 인접. 조작 2: 맨마커가 2칸 이동해 A 포처에 인접. 박투박 공짜 1칸 전진.

### 3.3 라운드 2

**A 턴.** 조작 1: 레지스타가 거리 5 의 윙어에게 롱패스. 목표 11+, 레지스타 자기 진영 +2, 볼 위너 인접 -1, 윙어 마킹 없음 → 10+. d20 = 9, 실패. 윙어에 인접한 상대가 없으므로 공은 윙어 칸에 루스볼. 조작 2: 윙어가 트래핑(조작 1회, 판정 없음). 소유. 박투박 공짜 1칸.

**B 턴.** 조작 1: B 풀백이 터치라인 열로 2칸(+1 = 3칸) 이동해 윙어에 인접. 조작 2: 풀백이 태클. 목표 11+, DF +1, 풀백 터치라인 +2, 윙어 이점 없음 → 8+. d20 = 7, 실패. 변화 없음.

### 3.4 라운드 3

**A 턴.** 조작 1: 윙어가 터치라인 열에서 PA 안 포처에게 거리 4 크로스. 롱패스 11+, 윙어 크로스 +2, 포처에 인접한 맨마커 -2 → 11+. d20 = 16, 성공. 포처 소유. 조작 2: 포처가 거리 2 에서 슛. 목표 10+, 포처 PA +3, 슛 스토퍼 PA 안 -4, 리베로 PA 안 -1, 인접 맨마커 -1 → 보정 합계 -3 → 13+. d20 = 11, 실패. 공은 B 슛 스토퍼에게.

**B 턴.** 조작 1: 슛 스토퍼가 거리 6 의 타겟맨에게 롱패스(골킥). 11+, 타겟맨 수신 +3, 타겟맨에 인접한 A 스토퍼 -2, A 에어리얼 센터백 인접 -2 추가 → 8+. d20 = 12, 성공. 타겟맨 소유. 레이오프: 조작 없이 인접한 인사이드 포워드에게 숏패스, 6+, 마킹 없음. d20 = 4, 실패. 인사이드 포워드에 인접한 A 선수 없음 → 루스볼. 조작 2: 인사이드 포워드가 트래핑.

### 3.5 라운드 4 (득점 예)

**A 턴.** 조작 1: A 스토퍼가 인사이드 포워드에게 태클. 11+, DF +1, 스토퍼 +2 → 8+. d20 = 3, 실패. 조작 2: 폴스 나인이 2칸 복귀 후 이점으로 박투박을 1칸 이동시켜 패스 길을 막는다.

**B 턴.** 조작 1: 인사이드 포워드가 이점으로 1칸 이동해 A 스토퍼와 떨어진 뒤 같은 조작으로 거리 3 슛. 목표 14+, 슈터 인접 상대 없음, A 스위퍼 키퍼 PA 안 -2 → 16+. d20 = 18, 성공. **B 1 : 0 A.** 양 팀 킥오프 배치로 리셋, A 가 실점했으므로 A 킥오프. 라운드 5 부터 계속.

### 시나리오에서 드러난 규칙 빈 곳

- 루스볼이 놓인 칸에 선수가 있을 때 상대는 아무것도 못 한다. 트래핑 전에 태클을 허용할지 결정 필요 (Q-17 에 추가 후보).
- 타겟맨 레이오프 실패로 루스볼이 생기면 같은 턴에 조작을 써서 트래핑해야 해서, 레이오프가 오히려 손해일 수 있다. 레이오프를 "받은 즉시 판정 없이" 로 바꾸는 안 검토.
- 골 후 리셋이 라운드 중간에 일어나면 그 라운드의 남은 턴을 어떻게 하는지 정해야 한다 (Q-10).
- 박투박의 공짜 1칸이 태클 회피 수단으로 강하다. "이동력 2 이하로 조작될 때만" 같은 제한이 필요한지 플레이테스트 항목.
