# 카드 구조 v2 제안: 성향 토큰 (2026-09-08, 논의용)

**상태: D-9 로 확정 (2026-09-08). 덱 v2(assets/deck-v2-2026-09-08.md)로 구현. 이동 폭·누적 이동 같은 세부는 덱 문서가 우선한다.** 원래 상태: 논의 중 (2차). 사용자의 방향(주사위 최종 판정 유지, 계산 층 제거, 특성별 성향 토큰 0~3개, 상쇄로 value 하락, 강한 성향은 카운터에 크게 진다)에 2차 지적(맞대기에 힘겨루기 a−d 형도 필요, 보정치 합산이 아니라 밴드 범위가 바뀌는 판정이 메인)을 반영한 안이다. 구조가 픽스되면 덱 v2 를 만든다. 결정 지점은 Q-36.

## 1. 한 문장 요약

카드에는 숫자 대신 **성향 아이콘**이 찍혀 있다. 두 장을 내면 특성마다 아이콘을 세고, 반대 성향끼리는 지우고, 남은 성향을 상대 조합과 특성별로 맞댄다. 맞댄 결과는 합산되지 않는다. **특성마다 주사위 결과표의 경계 하나를 움직인다.** 템포는 카운터 경계, 조직은 소유 상실 경계, 폭은 전진 경계, 공간은 결정적 찬스 경계. 그래서 매치업마다 결과표의 모양 자체가 달라진다.

## 2. 특성과 성향 (가안: 특성 4개, 특성마다 성향 2개)

공격과 수비가 같은 특성 축을 쓰되 성향 이름은 편마다 다르다. 특성마다 "누가 누구를 잡는가" 는 2×2 로 고정이라 참조 카드 한 장에 다 들어간다.

특성마다 공격 성향 2개 × 수비 성향 2개 = 4칸이고, 칸마다 맞대기 유형이 정해져 있다. 유형은 셋이다.

- **뚫음** +(a+d): 상대가 걸수록 더 크게 뚫린다. 공격 유리 카운터.
- **잡힘** −(a+d): 내가 걸수록 더 크게 잡힌다. 수비 유리 카운터.
- **힘겨루기** a−d: 센 쪽이 차이만큼 이긴다. 진폭이 작아 밸런스 조정용.

| 특성 | 공격 ⟷ | 수비 ⟷ | 칸별 유형 (공격 성향 · 수비 성향) | 축구에서의 뜻 |
|---|---|---|---|---|
| 템포 → 카운터 경계 | 점유 ⟷ 전환 | 압박 ⟷ 후퇴 | 점유·압박 힘겨루기 / 점유·후퇴 잡힘 / 전환·압박 뚫음 / 전환·후퇴 힘겨루기 | 점유 대 압박은 프레스 저항의 싸움. 내려선 팀 앞의 점유는 공허하다(sterile). 역습은 압박 뒷공간을 찌른다. 역습 대 내려선 블록은 속도 대 숫자의 싸움 |
| 폭 → 전진 경계 | 측면 ⟷ 중앙 | 측면 봉쇄 ⟷ 중앙 밀집 | 측면·봉쇄 힘겨루기 / 측면·밀집 뚫음 / 중앙·봉쇄 잡힘 / 중앙·밀집 힘겨루기 | 통로를 맞게 막으면 힘싸움, 잘못 막으면 반대편이 열린다. 바깥으로 모는 수비 앞에서 중앙 공략은 막힌다 |
| 공간 → 결정적 찬스 경계 | 뒷공간 ⟷ 발밑 | 하이 라인 ⟷ 딥 라인 | 뒷공간·하이 뚫음 / 뒷공간·딥 잡힘 / 발밑·하이 힘겨루기 / 발밑·딥 힘겨루기 | 라인 뒤를 노리는 축구는 도박이다. 높은 라인엔 크게 통하고 내려선 라인엔 오프사이드와 키퍼에 걸린다. 발밑 축구는 어느 라인 앞에서든 힘싸움이다 |
| 조직 → 소유 상실 경계 | 패턴 ⟷ 개인 | 지역 ⟷ 대인 | 패턴·지역 힘겨루기 / 패턴·대인 뚫음 / 개인·지역 잡힘 / 개인·대인 힘겨루기 | 패턴 플레이는 마커를 끌고 다니고, 지역 수비의 커버는 1대1 을 삼킨다. 패턴 대 지역, 개인 대 대인은 질의 싸움 |

규칙성: 특성마다 뚫음 1, 잡힘 1, 힘겨루기 2. 어느 성향이 도박(카운터 양쪽)이고 어느 성향이 힘싸움인지는 특성마다 다르다. 템포는 전환이 도박, 공간은 뒷공간이 도박, 폭·조직은 대각선이 힘싸움이다.

## 3. 카드

- 카드 한 장에 아이콘 0~3개씩, 특성 2~3개에 걸쳐 총 3~5개. 숫자 없음.
- 예 (공격): 롱볼 = 전환 2, 뒷공간 2 / 티키타카 = 점유 3, 패턴 1 / 타겟맨 활용 = 전환 1, 발밑 1, 개인 2 / 측면 오버로드 = 점유 1, 측면 3 / 스루패스 = 전환 1, 중앙 1, 뒷공간 2 / 폴스 나인 = 점유 1, 발밑 2, 패턴 2.
- 예 (수비): 하이 프레스 = 압박 3, 하이 라인 1 / 로우 블록 = 후퇴 3, 딥 라인 1 / 5백 = 후퇴 1, 측면 봉쇄 2, 지역 1 / 게겐프레싱 = 압박 2, 대인 2 / 오프사이드 트랩 = 하이 라인 3.
- 카드 이름과 그림이 곧 축구 개념이고, 아이콘이 그 개념의 성향이다. 텍스트 효과는 없거나 극소수(4절).

## 4. 판정: 밴드 트랙

주사위는 d20 이고, 결과표는 20칸 트랙 위에 마커 4개로 표현한다. 마커가 밴드의 경계다.

| 경계 | 기본 위치 | 아래 | 위 | 움직이는 특성 |
|---|---|---|---|---|
| ① 카운터 경계 | 2 | 카운터 (1~2) | 소유 상실 | 템포 |
| ② 소유 상실 경계 | 8 | 소유 상실 (3~8) | 전진 | 조직 |
| ③ 전진 경계 | 14 | 전진 (9~14) | 찬스 | 폭 |
| ④ 찬스 경계 | 18 | 찬스 (15~18) | 결정적 찬스 (19~20) | 공간 |

절차:

1. 두 장을 낸 뒤 특성마다 아이콘을 세고, 반대 성향은 1:1 로 지운다. 지운 쌍 하나마다 혼선 −1 을 그 특성 결과에 더한다.
2. 특성마다 내 세기 a, 상대 세기 d 로 칸 유형에 따라 결과 v 를 낸다: 뚫음 +(a+d), 잡힘 −(a+d), 힘겨루기 a−d. 한쪽만 성향이 있으면 그쪽에 ±세기. 둘 다 없으면 0.
3. **각 특성의 v 만큼 담당 경계를 왼쪽(아래)으로 옮긴다.** v 가 양수면 공격에 유리한 쪽으로 밴드가 넓어지고, 음수면 오른쪽으로 옮겨 나쁜 밴드가 넓어진다. 경계는 1~20 안에 머문다. 경계끼리 순서가 뒤집히면 밀린 경계가 함께 끌려간다: 뒤 경계가 앞 경계보다 왼쪽으로 가면 앞 경계도 그 자리까지 당겨지고(사이 밴드 소멸), 앞 경계가 뒤 경계보다 오른쪽으로 가면 뒤 경계도 밀려난다.
4. d20 을 굴려 마커 위치로 결과를 읽는다.

합산 M 은 없다. 특성 4개가 각각 결과의 다른 면을 바꾼다: 템포는 잃었을 때 역습을 맞느냐, 조직은 공을 지키느냐, 폭은 얼마나 전진하느냐, 공간은 기회의 질이다. 그래서 "공을 안 잃지만 큰 기회도 없는 조합" 과 "기회는 크지만 역습을 맞는 조합" 이 같은 평균에서도 다른 모양이 된다.

보정치는 5절의 텍스트 효과로만, 그것도 특정 특성의 v 에만 붙는다 (예: "타겟맨 활용: 공간 판정 +1").

### 예시

공격: 롱볼(전환 2, 뒷공간 2) + 라인 브레이킹 런(전환 1, 뒷공간 3) → 전환 3, 뒷공간 5.

- 수비 하이 프레스(압박 3, 하이 라인 1) + 오프사이드 트랩(하이 라인 3) → 압박 3, 하이 라인 4.
  - 템포: 전환·압박 = 뚫음 +(3+3) = +6 → 카운터 경계 2 → 1 (0 이하로 못 감. 카운터 없음).
  - 공간: 뒷공간·하이 = 뚫음 +(5+4) = +9 → 찬스 경계 18 → 9. 폭·조직은 양쪽 다 없음 → 그대로.
  - 찬스 경계(④)가 9 로 가면 전진 경계(③, 14)보다 왼쪽이므로 ③도 9 로 끌려가고, 전진 밴드와 찬스 밴드는 사라진다. 최종: 1 카운터, 2~8 소유 상실, 9~20 결정적 찬스. 60% 로 결정적 기회. 압박하고 라인 올린 팀이 롱볼 한 방에 뒤집힌 장면.
- 수비 로우 블록(후퇴 3, 딥 라인 1) + 딥 라인 강화(딥 라인 2, 지역 1) → 후퇴 3, 딥 라인 3, 지역 1.
  - 템포: 전환·후퇴 = 힘겨루기 3−3 = 0. 공간: 뒷공간·딥 = 잡힘 −(5+3) = −8 → 찬스 경계 18 → 20 을 넘어 결정적 찬스 소멸, 찬스 밴드도 좁아짐. 조직: 상대만 지역 1 → −1 → 소유 상실 경계 8 → 9.
  - 최종: 1~2 카운터, 3~9 소유 상실, 10~14 전진, 15~20 찬스, 결정적 없음. 같은 공격이 내려선 팀 앞에서는 기회의 질이 사라진다. 역습 대 내려선 블록이 힘겨루기라 카운터는 안 맞는다.
- 공격을 티키타카(점유 3, 패턴 1) + 롱볼로 바꾸면 템포에서 점유 3 과 전환 2 가 상쇄되어 점유 1, 혼선 −2. 점유 1 로 후퇴 3 을 만나면 잡힘 −(1+3) −2 = −6 → 카운터 경계 2 → 8. 정체성 없는 조합은 잃을 때 역습까지 맞는다.

## 5. 텍스트 효과 (최소)

계산을 늘리지 않는 종류만, 카드 4~6장에 한 줄:

- 한 방: 2d20 중 큰 값 (중거리 슛, 개인 돌파).
- 안전: 카운터 경계를 1 로 고정 (템포 조절).
- 끊기: 찬스 경계를 20 으로 고정, 결정적 찬스 없음 (전술적 파울).
- 지우개: 상대의 "한 방" 무효 (컴팩트).
- 특성 보너스: "공간 판정 +1" 처럼 특정 특성의 v 에만 더하는 보정. 밸런스 조정용으로 소수 카드에만.

이 다섯 외의 텍스트는 두지 않는다. 시너지·상성은 전부 아이콘으로만 표현한다.

## 6. 이 구조가 만드는 고민

- 얼마나 몰아넣을까: 같은 성향 두 장은 세기 5~6 이 되어 뚫으면 +10, 잡히면 −10. 섞으면 세기가 낮고 진폭도 작다. 리드 중엔 섞고, 쫓길 땐 몰아넣는 게 자연스럽다.
- 첫 장으로 뭘 보여 줄까: 수비 1장 → 공격 1장 → 동시 1장의 순서라 첫 장은 "이 특성에 걸겠다" 는 선언이다. 두 번째 장으로 강화할지, 다른 특성으로 갈아탈지, 상대 첫 장을 카운터할지가 숨은 결정이다.
- 상대 첫 장을 읽기: 수비가 압박 3 을 보였다면 공격은 전환으로 뚫거나 점유를 피한다. 수비의 둘째 장이 후퇴로 "취소" 하면 상쇄 혼선을 스스로 먹으므로 그런 블러프엔 비용이 있다.

## 7. 내 의견 (논의용)

1. 특성은 3개보다 4개가 낫다. 3개면 조합이 금방 읽히고, 4개면 카드마다 2~3개 특성만 쓰게 해서 세는 부담은 그대로 둔 채 조합 수가 늘어난다. 5개는 참조 카드가 길어진다.
2. 혼선 −1 은 꼭 넣자. 상쇄가 그냥 0 이면 "섞은 조합" 이 안전한 중립이 되어 사용자가 원한 "상쇄되면 value 가 낮아진다" 가 안 나온다.
3. 맞대기는 두 형을 섞는다. 카운터(±(a+d))는 진폭을, 힘겨루기(a−d)는 밸런스 조정 폭을 준다. 특성마다 뚫음 1·잡힘 1·힘겨루기 2 로 두면 어느 성향이 도박이고 어느 성향이 힘싸움인지가 특성의 개성이 된다.
4. 한쪽만 성향이 있는 특성은 ±세기로 두자. 그래야 "상대가 안 건 특성에 걸기" 가 무난한 이득이 되고, 상대의 카운터가 없는 특성으로 도망치는 플레이가 생긴다.
5. 판정은 밴드 트랙이 메인이다. 특성 4개가 경계 4개를 하나씩 맡으니 합산이 없고, 결과표의 모양이 매치업마다 달라진다. 물리적으로는 20칸 트랙에 마커 4개라 손으로 옮기기 쉽다.
6. 텍스트 효과는 5절의 다섯으로 제한하자. v1 에서 계산을 늘린 것은 텍스트 효과가 아니라 숫자 층이었지만, 텍스트도 늘리면 결국 같은 문제가 된다.
7. 우려 하나: 뚫음 +(a+d) 는 양쪽이 같은 특성에 몰빵하면 +12 까지 가서 경계가 트랙 끝에 붙는다. 그 특성의 밴드 하나가 통째로 사라지는 것은 의도(완전히 뚫림)지만, 다른 경계까지 밀어내지는 않도록 카드당 아이콘 총 5, 특성당 3 상한을 둔다. 덱을 만들 때 평가기로 분포를 확인한다.
8. 평가는 v1 처럼 190×190 을 돌려 조합 value 분산·중복·등급 편차를 다시 잰다. 이 구조는 공식이 짧아 평가기가 훨씬 단순하다.

## 8. 정할 것 (Q-36)

1. 특성 수와 이름: 위 4개(템포·폭·공간·조직)로 갈지, 바꿀지.
2. 카드당 아이콘 상한: 특성당 3, 카드당 총 5 (가안).
3. 상쇄 규칙: 1:1 지우기 + 혼선 −1 (가안).
4. 맞대기 유형: 특성마다 뚫음 1·잡힘 1·힘겨루기 2 (2절 표의 배치), 한쪽만 ±세기 (가안).
5. 판정: d20 밴드 트랙, 경계 4개 기본 위치 2/8/14/18, 특성→경계 배정 (템포→카운터, 조직→소유 상실, 폭→전진, 공간→찬스) (가안).
6. 텍스트 효과: 5종만 (가안).
7. 등급: v1 의 S/C/X 를 유지할지, 토큰 총량으로 등급을 대신할지.
