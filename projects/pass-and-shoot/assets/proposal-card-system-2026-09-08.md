# 패스 앤 슛 카드 시스템 제안 B: 2+2 지시 대결과 공유 전술판 (2026-09-08)

**상태: 제안.** 확정(D-8)은 이렇다: 선수 카드 없음, 한 라운드에 2장씩(수비 1 → 공격 1 → 동시 1씩), 2+2 상성 판정, 기본 카드는 공용·상시, 특수 카드는 뽑은 쪽만 갖고 사용 후 공유, 다양성과 선택지 수의 동시 통제. 아래는 그것을 채우는 설계이며 결정 지점은 Q-28, Q-29, Q-31~Q-35.

설계 기준은 D-7: 규칙마다 실제 축구의 어떤 고민에 대응하는지 말할 수 있어야 한다.

## 1. 라운드 구조

### 1.1 슬롯 4개

한 라운드는 공격 국면 하나다. 카드는 슬롯에 낸다.

| 순서 | 슬롯 | 누가 | 축구에서의 뜻 | 공개 |
|---|---|---|---|---|
| 1 | D1 수비 진형 | 수비 | 어디에 블록을 세우나 | 먼저 공개 |
| 2 | A1 공격 전개 | 공격 | 그 블록을 보고 어떻게 전진하나 | 공개 |
| 3 | D2 수비 대응 + A2 공격 마무리 | 양쪽 | 세부 의도. 서로 모른다 | 동시 공개 |

수비가 먼저 보이고 공격이 반응하고 의도는 숨기는 것이 실제 축구의 정보 구조다. 플레이어는 한 번에 한 슬롯만 고른다. 이것이 선택지 통제의 첫 번째 장치다.

### 1.2 기본 카드 12장 (공용, 소모 없음)

각자 앞에 같은 지시판을 펼쳐 둔다. 슬롯마다 3장. 언제든 쓸 수 있고 사라지지 않는다.

| 슬롯 | 기본 카드 |
|---|---|
| D1 진형 | 하이 프레스, 미들 블록, 로우 블록 |
| A1 전개 | 후방 빌드업, 롱볼, 중앙 침투 |
| D2 대응 | 지역 수비, 맨마킹, 오프사이드 트랩 |
| A2 마무리 | 크로스, 스루패스, 중거리 슛 |

### 1.3 상성표 2개 (각 3×3, 순환)

D1 vs A1, D2 vs A2 를 각각 읽어 점수를 더한다. 표는 라틴 방진이라 어떤 카드도 하나를 이기고 하나에 지고 하나와 비긴다. 모두 가안.

진형 vs 전개:

| 공격 ＼ 수비 | 하이 프레스 | 미들 블록 | 로우 블록 |
|---|---|---|---|
| 후방 빌드업 | -1 (높은 곳에서 뺏김) | 0 | +1 (저항 없이 전진) |
| 롱볼 | +1 (프레스 뒷공간) | -1 (세컨볼 회수) | 0 |
| 중앙 침투 | 0 | +1 (라인 사이) | -1 (공간 없음) |

대응 vs 마무리:

| 공격 ＼ 수비 | 지역 수비 | 맨마킹 | 오프사이드 트랩 |
|---|---|---|---|
| 크로스 | -1 (박스 밀집) | +1 (마커가 끌려 나감) | 0 |
| 스루패스 | +1 (존 사이) | 0 | -1 (걸림) |
| 중거리 슛 | 0 | -1 (밀착 차단) | +1 (라인 앞 공간) |

### 1.4 결과 (점수 합 -2 ~ +2, 특수 카드로 ±1 더)

존 트랙은 3칸: 자기 진영 / 중원 / 상대 진영 (Q-28). 킥오프는 중원.

| 합 | 결과 | 축구에서의 뜻 |
|---|---|---|
| -2 이하 | 소유 상실 + 카운터. 상대는 공을 한 칸 전진한 위치에서 다음 라운드를 시작 | 압박에 뺏기고 역습 허용 |
| -1 | 소유 상실. 공 위치 그대로 (상대 시점으로 뒤집힘) | 공격 무산 |
| 0 | 유지. 공 위치 그대로 | 볼 돌리기 |
| +1 | 전진 1칸. 상대 진영에서면 찬스 등급 1 | 진입 |
| +2 | 전진 2칸. 상대 진영에서면 찬스 등급 2 | 뚫림 |
| +3 이상 | 찬스 등급 3 | 결정적 기회 |

공을 유지·전진하면 같은 팀이 다음 라운드도 공격한다. 소유 상실이면 상대가 공격한다. 라운드 수는 누가 공격하든 1씩 센다.

### 1.5 슈팅 (Q-31)

찬스가 나면 슈팅. 제안은 카드만으로: 슈터가 좌·중·우 중 하나를 엎어 놓고 GK 가 막을 칸을 고른다. 찬스 등급이 GK 가 막을 수 있는 칸 수를 정한다: 등급 1 은 2칸(골 확률 1/3), 등급 2 는 1칸(2/3), 등급 3 은 슈터가 두 칸을 지정하고 GK 는 한 칸(골 확률 5/6 에 가깝게 조정). 골이면 킥오프(중원), 실점 팀 공격. 실패면 골킥: 상대 소유, 상대 자기 진영. 대안은 20면체 판정.

### 1.6 시간

하프당 라운드 8 (가안). "볼 소유" 계열 카드는 결과를 0 으로 고정하고 라운드를 1 더 소모한다(시간 죽이기). 동점 처리는 Q-9.

### 1.7 강도 토큰 (선택 층, Q-29)

하이 프레스와 고강도 특수 카드는 토큰 1 을 낸다. 하프당 5, 하프타임 회복. 없으면 낼 수 없다. 이것이 "언제 압박하나". 시스템 수를 줄이려면 뺀다.

## 2. 카드 풀: 다양성과 선택지 수의 동시 통제 (D-8 5항)

### 2.1 세 층

| 층 | 누가 | 보이나 | 사라지나 |
|---|---|---|---|
| 기본 카드 12 | 양쪽 지시판 | 항상 | 없음 |
| 특수 카드 (손패) | 뽑은 사람 | 상대에게 안 보임 | 내면 공유판으로 |
| 공유 전술판 | 양쪽 | 항상 펼침 | 상한을 넘으면 낡은 것부터 제거 (Q-32) |

### 2.2 특수 카드의 일생

1. 셋업에서 각자 특수 덱에서 4장을 뽑는다 (Q-34). 상대는 내 손패를 모른다.
2. 특수 카드는 슬롯 태그가 있어 그 슬롯에 기본 카드 대신 낸다. 조건이 붙은 카드는 조건이 맞을 때만 낼 수 있다.
3. 처음 낼 때 +1 (서프라이즈, Q-33). 상대는 이 전술을 처음 본다.
4. 판정이 끝나면 카드는 공유 전술판에 펼쳐진다. 이제 양쪽이 언제든 기본 카드처럼 쓴다. 보너스는 없다.
5. 공유판이 상한을 넘으면 가장 오래된 카드가 빠진다. 전술은 유행하고 낡는다.

이 구조가 만드는 고민: 내 비장의 전술을 언제 꺼낼까. 꺼내면 한 번은 통하지만 다음부터 상대도 쓴다. 상대 손패는 모르지만 공유판은 다 보인다.

### 2.3 선택지 수 통제 장치 (한 번에 보는 수 ≤ 6~7)

1. 슬롯 순서 공개: 한 번에 한 슬롯만 고른다. 기본 3장이 바닥.
2. 슬롯 태그: 손패 4장이 슬롯별로 흩어져 한 슬롯에 보통 1장.
3. 공유판 상한: 슬롯당 2장 (Q-32). 넘치면 낡은 것 제거.
4. 조건부 카드: 역습(직전 라운드에 소유 획득), 볼 소유(리드 중), 세트피스(직전 결과가 코너)처럼 상황이 맞을 때만 선택지에 든다.
5. 손패 상한 4~5, 드로우는 하프타임과 실점 후에만 (Q-34).

계산: 슬롯당 기본 3 + 공유 ≤2 + 손패 ≤1~2 = 최대 6~7. 게임 초반은 3~4.

### 2.4 항상 쓸 수 있어야 하는 전술 (D-8 3항)

블록 높이 3종, 전개 3종, 대응 3종, 마무리 3종은 축구에서 언제든 가능한 지시라 전부 기본 카드로 두어 소모 없이 항상 쓴다. 특수 카드는 "특정 팀만 준비해 온 것" 이다. 기본으로 올려야 할 전술이 플레이테스트에서 드러나면 기본을 4장으로 늘리되 상성표는 순환을 유지한다.

## 3. 특수 카드 예시 (슬롯당 3장, 총 12장. 덱 목표는 Q-35)

효과는 전부 가안. 괄호는 대응하는 축구의 고민.

| 슬롯 | 카드 | 조건 | 효과 |
|---|---|---|---|
| D1 | 게겐프레싱 | 없음. 토큰 1 | 하이 프레스 취급. 이 라운드에 소유를 뺏으면 카운터 등급 +1 (뺏자마자 찌르기) |
| D1 | 5백 | 없음 | 로우 블록 취급. vs 크로스 -1 추가. 이 라운드 소유를 얻어도 카운터 없음 (안전 우선) |
| D1 | 압박 트리거 | 없음 | 미들 블록 취급. 상대 A1 이 후방 빌드업이면 하이 프레스로 취급 (선택적 압박) |
| A1 | 역습 | 직전 라운드에 소유 획득 | 진형 표 대신 vs 하이 프레스 +2, 미들 블록 +1, 로우 블록 -1 (전환 순간) |
| A1 | 티키타카 | 없음 | 후방 빌드업 취급. vs 하이 프레스 -1 을 0 으로 (프레스 저항) |
| A1 | 사이드 체인지 | 없음 | vs 미들 블록 +1, 로우 블록 0, 하이 프레스 -1 (블록 흔들기) |
| D2 | 전술적 파울 | 하프당 1회 | 상대 A2 를 무효로 하고 결과를 0 으로. 사용 후 공유되지 않고 제거. 두 번째 사용은 퇴장: 남은 라운드 D1 -1 (리스크 관리) |
| D2 | 박스 안 밀집 | D1 이 로우 블록 | 지역 수비 취급. vs 크로스 -1 추가, vs 중거리 슛 +1 허용 (무엇을 내줄까) |
| D2 | 스위퍼 키퍼 | 없음 | 오프사이드 트랩 취급. vs 스루패스 -1 유지, vs 롱볼 계열 실패를 0 으로 (뒷공간 보험) |
| A2 | 오버래핑 풀백 | 없음. 토큰 1 | 크로스 취급 +1. 이 라운드 -2 가 되면 카운터 등급 +1 추가 (뒷공간 노출) |
| A2 | 볼 소유 | 리드 중 | 결과를 0 으로 고정, 라운드 1 추가 소모 (시간 죽이기) |
| A2 | 개인 돌파 | 없음 | 상대 D2 가 맨마킹이면 +1, 지역 수비면 -1, 실패 시 -2 (한 방 승부) |

역할 이름(타겟맨, 드리블러, 레지스타)은 선수 카드가 아니라 특수 카드의 이름과 그림으로 쓸 수 있다 (Q-26).

## 4. 시나리오 스케치 (전반 1~3라운드)

- R1. A 공격(중원). B 가 D1 미들 블록 공개. A 는 손패의 사이드 체인지를 A1 로 낸다(첫 사용 +1). 동시 공개: B 지역 수비, A 스루패스. 점수: 사이드 체인지 vs 미들 +1, 스루패스 vs 지역 +1, 서프라이즈 +1 = +3 → 찬스 등급 3. 슈팅: A 가 좌·우 두 칸 지정, B GK 중앙 → 골. 사이드 체인지는 공유판으로 간다.
- R2. B 공격(킥오프, 중원). A 가 D1 하이 프레스(토큰 1). B 는 공유판의 사이드 체인지를 그대로 쓴다: vs 하이 프레스 -1. 동시 공개: A 맨마킹, B 크로스 +1. 합 0 → 유지, 중원.
- R3. B 공격(중원). A 가 D1 로우 블록으로 내려선다(리드 관리). B 후방 빌드업 +1. 동시: A 오프사이드 트랩, B 스루패스 -1. 합 0 → 유지. B 는 시간을 쓰고 있다.

세 라운드에 블록 높이 선택, 전술 공개 시점, 공유된 전술의 역이용, 리드 관리가 다 나온다.

## 5. 리서치 실패 사례에 대한 방어

- 단순 값 비교(Hat-Trick): 순환 상성이라 우세 카드가 없고, 두 슬롯이 서로 보정한다.
- 운 과다(Schuss und Tor): 국면은 주사위 없이 카드로만 결정. 운은 슈팅의 읽기 싸움뿐.
- 공이 안 나감(카드 스트라이커): 존 3칸이라 성공 라운드 2번이면 슛. 카운터 결과로 템포.
- 규칙 과다(Soccer City): 기본 12장, 3×3 표 2개, 결과표 1개. 특수 카드는 한 줄 텍스트.
- 선택지 폭발: 슬롯 순서, 슬롯 태그, 공유판 상한, 조건부 카드, 손패 상한 5중 통제.

## 6. 목업으로 확인할 것

- 상성표 두 개의 라틴 방진이 실제로 "항상 옳은 카드" 를 없애는지 (봇 대전).
- 판당 골 수 (목표는 사람이 정한다. 가안 2~3골).
- 공격 선공 정보 이점이 과한지 (공격 승률).
- 공유판 상한 2 에서 후반 선택지가 몇 개까지 가는지.
