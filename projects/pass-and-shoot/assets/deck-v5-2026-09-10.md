**상태: 구조는 D-12~D-18 로 확정, 카드 배치는 제안.** 2026-09-09~10 의 결정을 모두 반영한 첫 덱이다: 마커는 특성마다 2개를 맡아 합쳐서 한 번에 옮기고(닿으면 밀기), 맞대기는 "잡히면 −d, 안 잡히면 +a", 공 위치는 −2~2 다섯 단계를 두 사람이 공유하며 2 를 넘으면 골이다. 슈팅 굴림도 주사위를 두 번 굴리는 효과도 없다. 카드 40장은 저마다 고유한 효과 한 줄을 갖고, 겹침은 단계 순서로 푼다(D-18). 모든 수치는 `playtests/deck-v5-eval.js` 로 재현된다.

## 0. 요구 조건과 결과

1. 카드 value 편차폭 ≤ 5 (공격 20장, 수비 20장 각각. 가장 센 카드와 가장 약한 카드의 차이)
2. 카운터 존재: 모든 공격 조합에 value 40 이하로 막는 수비 조합이 있고, 모든 수비 조합에 60 이상으로 뚫는 공격 조합이 있다

## 1. 보드: 공 위치 트랙과 판정 트랙

- **공 위치 트랙**: −2 / −1 / 0 / 1 / 2 다섯 칸. 두 사람이 마주 보고 공유한다. 공격자 기준으로 양수가 상대 골문 쪽이고, 상대 입장에서는 부호가 반대다. 자기 PA / 자기 진영 / 중원 / 상대 진영 / 상대 PA 로 읽는다. 킥오프는 0.
- **판정 트랙**: 1~20 의 숫자 칸, 마커 ①②③④ (기본 4 / 8 / 12 / 16, 쉬는 상태에서 다섯 결과가 20% 씩). 마커는 서로 다른 칸에 순서대로 놓이고(① < ② < ③ < ④), ④ 는 19 를 넘지 않는다. 그래서 다섯 결과 모두 최소 한 눈(1/20)은 남는다. d20 이 ① 이하면 카운터, ② 이하면 소유 상실, ③ 이하면 교착, ④ 이하면 전진, 그 위면 돌파.

## 2. 한 라운드

1. **카드**: 각자 시스템 1장(세워 둔 것, 공개) + 플레이 1장(뒷면, 동시 공개). 수비자가 먼저 시스템을 유지하거나 바꾸고, 공격자가 그 다음, 플레이는 동시에 뒤집는다 (D-17, D-8 의 순서). 시스템을 바꾼 라운드에는 자기 마커가 1칸 불리하다(공격 ① +1, 수비 ④ −1).
2. **세기**: 특성(색)마다 두 장의 아이콘을 더한다. 같은 색의 반대 성향은 1:1 로 지운다(혼선 벌점은 없다, D-16). 남은 세기가 2 미만이면 그 특성은 없는 것. "무시" 카드는 이 전에 상대 아이콘 1개를 뺀다.
3. **맞대기**: 특성마다 내 세기 a, 상대 세기 d. 상대 방패가 내 성향을 노리고 있거나 내가 그 특성이 없으면 **−d**. 상대 방패가 다른 성향을 노리고 있거나 상대가 그 특성이 없으면 **+a**. 둘 다 없으면 0. 읽기에서 이긴 쪽이 자기 판돈을 받는다.
4. **마커 이동**: 마커마다 맡은 두 특성의 결과를 더해 1점 = 1칸 옮긴다. 양수는 왼쪽.
   - ① 템포 + 공간 · ② 템포 + 조직 · ③ 조직 + 폭 · ④ 폭 + 공간
   - 많이 움직이는 마커부터 옮긴다. 옮기는 마커가 아직 안 옮긴 마커에 닿으면 그 마커를 옆 칸에 붙여서 밀고 간다(밀린 마커가 또 다른 마커에 닿으면 그것도 민다). 이미 옮긴 마커에 닿으면 그 옆 칸에서 멈춘다. 1 과 19 는 벽이다. 마커는 겹치지 않는다.
   - 밀려난 마커는 자기 차례가 오면 밀려난 자리에서 자기 이동량만큼 간다(원래 자리로 돌아가서 재지 않는다). 그래서 마커를 순서대로 손으로 옮기기만 하면 된다.
5. **마커 효과**: 칸 이동 효과(시스템 교체 손해 ① +1 / ④ −1, 측면 오버로드의 ④ −1, 하이 라인의 ④ +1)를 모두 더한 뒤, 고정 효과(템포 조절 ① 을 1 로, 전술적 파울 ④ 를 19 로)를 적용한다. 그 다음 **d20**.
6. **결과 바꾸기**: "X 는 Y 로 본다" 류의 효과. 수비 카드(시스템 → 플레이) 먼저, 공격 카드(시스템 → 플레이) 나중, 각 효과는 한 번, 그 시점의 결과와 위치에 조건이 맞을 때만.
7. **공 위치 이동과 골**:

| 결과 | 실제 축구 | 처리 |
|---|---|---|
| 카운터 | 위험한 곳에서 뺏겨 역습을 맞는다 | 공격권 교대. 상대 기준 위치 +1. 내가 −2 였으면 바로 실점 |
| 소유 상실 | 공을 잃었지만 수비는 자리를 잡았다 | 공격권 교대. 위치 그대로(부호만 반대) |
| 교착 | 공은 지켰지만 뚫지 못했다 | 같은 공격자. 위치 그대로 |
| 전진 | 공을 한 지역 위로 옮겼다 | 위치 +1. 2 였으면 골 |
| 돌파 | 수비 블록을 통째로 뚫었다 | 위치 +2. 1 이상이었으면 골 |

이동량 단계에서 추가 이동(롱볼·역습·얼리 크로스·라인 브레이킹 런·인버티드 윙어·스루패스·하이 라인)을 더하고 무효 효과(컴팩트·딥 라인)를 적용한 뒤, 도착 단계에서 오프사이드 트랩 → 골 판정 → 선방(슛 스토퍼) 순으로 본다. 골이 나면 실점 팀이 위치 0 에서 킥오프한다.

카드를 무작위로 낸다고 가정하면 한 라운드에 골이 나올 확률은 위치 0 에서 3.8%, 1 에서 16.3%, 2 에서 34.4% 이고, 카운터로 실점할 확률은 위치 −2 에서 19.0%, −1 에서 3.4%, 0 에서 1.4%다. 위치 0 킥오프에서 18 라운드를 돌리면 기대 골 라운드 이다. 경기 길이(하프당 라운드 수)는 Q-8 이다.

## 3. 마커 2개를 합쳐서 옮기는 이유

특성마다 마커 하나를 맡기면(v4 는 자기 마커와 오른쪽 마커 전부) 템포 1점이 공간 1점의 4.5배 가치였다. 특성마다 2개씩 맡되 "1번 특성부터 순서대로 옮기고 닿으면 밀기" 로 하면 마지막에 옮기는 특성이 앞 특성들이 옮긴 마커를 밀어내서 지배한다(공간 7.5 대 템포 1.3). 그래서 순서를 특성이 아니라 마커에 두었다. 마커마다 두 특성의 결과를 합쳐서 한 번에 옮기고 많이 움직이는 마커부터 처리하면 어느 특성도 지배하지 못한다. 자세한 비교는 assets/proposal-marker-flow-2026-09-09.md 5절.

배분의 개연성: 템포(①②)는 지면 공을 잃고 역습을 맞는 싸움, 조직(②③)은 수비 블록을 통과하느냐, 폭(③④)은 박스에 어떻게 닿느냐, 공간(④①)은 이기면 결정적이고 지면 오프사이드·걷어내기로 뒤가 열리는 하이 리스크 하이 리턴이다.

겹침의 예. 미들 블록(위치 0 에서 전진은 교착) 뒤에 하프스페이스 침투(위치 0·1 에서 교착은 전진)가 오면 전진으로 끝난다(수비 먼저, 공격 나중). 하이 라인(상대 돌파 +3)과 딥 라인은 둘 다 시스템이라 한 라운드에 같은 편에 설 수 없다. 롱볼(자기 진영에서 +1)에 컴팩트·딥 라인을 세우면 추가 이동이 지워진다.

## 5. 예

**상대가 하이 프레스 + 오프사이드 트랩**: 하이 프레스(시스템: 압박 2, 하이 라인 1, 대인 1. 효과: 공격자가 자기 진영(−2·−1)에 있으면 소유 상실은 카운터로 본다) + 오프사이드 트랩(플레이: 하이 라인 3, 지역 커버 2. 효과: 상대가 전진·돌파로 위치 2 에 도착하면 오프사이드: 소유 상실).

## 9. 카드마다 실제 축구의 무엇인가

이름은 감독과 해설이 실제로 쓰는 용어에서 가져왔고, 영어 이름은 그 용어의 통용 표기다. 효과는 4절 표. 아이콘과 종류(시스템/플레이)는 6절 표가 원본이다. 2개 이상 있는 성향이 그 전술의 정의에서 나온 주 성향이고, 1개짜리는 균형을 위해 미리 정한 후보 안에서 배치기가 고른 보조 아이콘이다(혼자서는 2 미만이라 없는 것이고, 같은 성향의 다른 카드와 겹칠 때만 산다).

### 공격

| 카드 | 실제 축구에서 | 왜 그 성향인가 |
|---|---|---|
| A01 후방 빌드업 (Build-up from the back) | 골키퍼·센터백부터 짧은 패스로 전진하는 조직적 빌드업 | 공을 오래 소유한다(점유). 발밑으로 받는 것과 정해진 패스 경로는 보조(발밑·패턴). 하이 프레스에 잡히면 자기 진영에서 뺏긴다 |
| A02 티키타카 (Tiki-taka) | 짧은 패스를 반복해 상대를 끌어내고 공간을 만드는 점유 축구 | 점유의 극단(점유). 삼각형 패턴으로 움직이고(패턴) 발밑으로 받는다 |
| A03 롱볼 (Long ball) | 후방에서 전방으로 한 번에 보내는 직선적 공격 | 빌드업을 건너뛰는 전환(전환)과 뒷공간으로 떨어지는 공(뒷공간) |
| A04 측면 오버로드 (Wide overload) | 한쪽 측면에 선수를 몰아 수적 우위를 만드는 것 | 측면에서 공을 돌리며(점유 3·측면) 우위를 만든다 |
| A05 스위칭 플레이 (Switch of play) | 긴 횡패스로 반대편 측면으로 전환하는 것 | 오버로드 뒤에 오는 반대편 공략. 측면과 점유 |
| A06 중거리 슛 (Long-range shot) | 박스 밖에서 때리는 슛 | 한 명이 때린다(개인) |
| A07 템포 조절 (Game management) | 리드할 때 공을 돌리며 경기를 관리하는 것 | 위험을 지우는 점유 |
| A08 오버래핑 풀백 (Overlapping full-back) | 풀백이 윙어 바깥으로 올라가는 움직임 | 폭을 만드는 가장 단순한 카드(측면). 올라가는 타이밍은 전환이 보조 |
| A09 얼리 크로스 (Early cross) | 수비가 자리 잡기 전에 일찍 올리는 크로스 | 빠른 전환 뒤 측면에서 바로 올린다(측면·전환) |
| A10 컷백 (Cut-back) | 엔드라인까지 가서 뒤로 내주는 패스 | 측면 끝까지 간다(측면). 정해진 지점으로 내주고 발밑에서 때리는 것은 보조 |
| A11 하프스페이스 침투 (Half-space run) | 측면과 중앙 사이 공간으로 파고드는 것 | 중앙 쪽 공간(중앙)을 패턴 움직임으로 파고든다(패턴) |
| A12 스루패스 (Through ball) | 수비 라인 사이로 찔러 넣는 패스 | 중앙에서 뒷공간으로(중앙·뒷공간), 정해진 타이밍의 침투(패턴) |
| A13 인버티드 윙어 (Inverted winger) | 반대발 윙어가 안쪽으로 접어 들어오는 것 | 측면에서 시작해 중앙으로(중앙) 개인 돌파(개인) |
| A14 세컨볼 회수 (Second ball) | 롱볼·경합 뒤 떨어지는 공을 먼저 줍는 것 | 전환(전환)과 떨어지는 공이 가는 뒷공간(뒷공간) |
| A15 파울 유도 (Winning free kicks) | 드리블로 파울을 끌어내 프리킥·코너를 얻는 것 | 개인 돌파 시도가 세트피스로 이어진다(개인). 측면에서 자주 나온다(보조) |
| A16 역습 (Counter-attack) | 공을 얻자마자 빠르게 앞으로 가는 것 | 전환의 극단(전환) |
| A17 라인 브레이킹 런 (Run in behind) | 수비 라인 뒤로 달리는 침투 | 라인 뒤 공간으로(뒷공간·전환) |
| A18 1대1 돌파 (Take-on) | 한 명이 수비 한 명을 제치는 것 | 개인 돌파(개인), 실제로 1대1 이 가장 많이 나오는 측면(측면) |
| A19 타겟맨 활용 (Hold-up play) | 큰 공격수에게 직선적으로 넣고 떨궈 주는 공을 받는 것 | 롱볼·다이렉트 전개(전환)가 주. 발밑으로 받아 지키는 홀드업(발밑)과 공중 경합(개인)은 보조 |
| A20 폴스 나인 (False nine) | 공격수가 내려와 센터백을 끌어내는 것 | 발밑으로 받아(발밑) 패턴을 만든다(패턴) |

### 수비

수비 아이콘의 영어 이름은 코칭 용어에서 가져왔다: Press(압박) / Drop(내려서기), Man-oriented(대인) / Zonal cover(지역 커버), Show inside(안으로 몰기 = 측면 봉쇄) / Show outside(밖으로 몰기 = 중앙 밀집), Deep line(딥 라인) / High line(하이 라인).

| 카드 | 실제 축구에서 | 왜 그 저지인가 |
|---|---|---|
| D01 하이 프레스 (High press) | 상대 진영에서부터 압박하는 것 | 점유와 발밑으로 받는 것을 막는다(점유 저지·발밑 저지). 패턴 저지는 보조. 롱볼에 뚫린다 |
| D02 미들 블록 (Mid block) | 중원에 블록을 세우고 기다리는 것 | 중앙을 막고(중앙 저지) 개인 돌파를 지역으로 받고(개인 저지) 전환을 지연한다(전환 저지) |
| D03 로우 블록 (Low block) | 자기 진영 깊숙이 내려서는 것 | 전환할 공간이 없다(전환 저지). 뒷공간 저지는 보조. 점유에는 약하다 |
| D04 지역 수비 (Zonal marking) | 사람이 아니라 공간을 지키는 것 | 개인 돌파를 지역으로 받고(개인 저지) 중앙을 촘촘히 한다(중앙 저지). 패턴 움직임에는 약하다 |
| D05 맨마킹 (Man-marking) | 사람을 따라붙는 것 | 패턴 움직임을 사람으로 따라간다(패턴 저지). 측면 봉쇄가 붙는다(측면 저지). 개인 돌파에 약하다 |
| D06 컴팩트 (Compactness) | 라인 간격을 좁혀 중앙을 촘촘히 하는 것 | 중앙 공간이 없다(중앙 저지) |
| D07 딥 라인 (Deep line) | 수비 라인을 내려 뒷공간을 없애는 것 | 뒷공간과 전환을 막는다(뒷공간 저지·전환 저지). 발밑으로 받는 것은 허용 |
| D08 게겐프레싱 (Counter-press) | 공을 잃은 직후 되찾는 압박 | 하이 프레스의 짧은 버전. 점유(점유 저지)와 패턴(패턴 저지)을 막고 |
| D09 하이 라인 (High line) | 수비 라인을 올려 공간을 압축하는 것 | 발밑 공간이 없고(발밑 저지) 점유를 압박한다(점유 저지). 뒷공간 카드에 뚫린다 |
| D10 오프사이드 트랩 (Offside trap) | 라인을 맞춰 올려 침투를 걸어 내는 것 | 하이 라인의 극단(발밑 저지) |
| D11 스위퍼 키퍼 (Sweeper-keeper) | 골키퍼가 나와 뒷공간을 정리하는 것 | 하이 라인의 보험이라 같은 방향의 저지(발밑 저지) |
| D12 박스 밀집 (Packing the box) | 페널티 박스 안에 몸을 던지는 것 | 뒷공간과 중앙을 몸으로 막는다(뒷공간 저지·중앙 저지) |
| D13 5백 (Back five) | 센터백 3명과 윙백으로 폭을 막는 것 | 폭을 막는 가장 직접적인 카드(측면 저지) |
| D14 더블 피봇 (Double pivot) | 수비형 미드필더 둘이 중앙을 잠그는 것 | 중앙을 막는다(중앙 저지). 개인 돌파 커버는 보조 |
| D15 측면 더블팀 (Doubling up wide) | 윙어를 바깥으로 몰고 둘이 막는 것 | 측면 오버로드·스위칭에 대한 답(측면 저지·패턴 저지) |
| D16 압박 트리거 (Pressing trigger) | 백패스·횡패스 순간에만 달려드는 것 | 점유하는 팀의 느슨한 패스를 노리는 함정(점유 저지) |
| D17 전술적 파울 (Tactical foul) | 위험해지기 전에 파울로 끊는 것 | 패턴 움직임을 몸으로 끊는다(패턴 저지) |
| D18 역습 세팅 (Sit and counter) | 뒤에 남았다가 뺏는 즉시 달리는 것 | 상대의 전환을 받아 되받아친다(전환 저지) |
| D19 슛 스토퍼 (Shot-stopper) | 골키퍼가 라인을 지키며 슛을 막는 것 | 뒷공간으로 오는 공을 골키퍼가 처리한다(뒷공간 저지) |
| D20 세트피스 수비 (Set-piece defending) | 코너·프리킥에서 지역과 사람을 섞어 막는 것 | 파울 유도·1대1의 결과인 세트피스에 대한 답(개인 저지). 뒷공간 저지는 보조 |

## 10. 읽는 법과 설계 메모

- 조합은 시스템 1장 + 플레이 1장이다(D-17). 상위 조합은 같은 성향을 시스템과 플레이에 쌓은 조합이다. 쌓기의 이득은 "안 잡히면 +a" 에서 그대로 나오고, 잡혀도 잃는 것은 상대 판돈 d 뿐이다. 1개짜리 잔재는 2 미만이라 없는 것이라서, 같은 특성을 모으는 조합이 정답이다.
- 하위 조합은 반대 성향이 섞여 서로 지워지는 조합이다.
- 균형은 아이콘 배치만으로 맞췄다. 최적화는 카드마다 미리 정한 보조 성향 후보 안에서만 0~2개를 움직였고 주 성향은 2~3 으로 유지했다. 효과가 겹치는 조합(되찾기+덫, 안전+세컨볼 같은)은 제약 없이 그대로 두고, 대신 조합 value 15~85 와 카운터 존재 조건으로 정답 조합을 막았다.
- 검증하지 않은 것: 사람이 실제로 고르는 조합, 위치 트랙 위의 라운드 연결과 경기당 골 수(Q-8), 공개 순서에서의 읽기 싸움. 카드 시트의 판정 트랙 시뮬레이터로 마커 이동과 눈별 결과는 손으로 확인할 수 있다.
