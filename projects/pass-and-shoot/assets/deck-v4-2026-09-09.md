## 1. 무엇이 문제였고 어떻게 고쳤나

v2·v3 은 상대가 내 성향을 막으면 −(a+d) 였다. 카운터의 힘이 *내* 토큰 수에 비례하니 많이 쌓을수록 잃을 것도 커져서, 쌓기는 이득이 아니라 도박이었다. v3 은 그 구멍을 호흡(+5)으로 메웠는데 그건 덧칠이다.

v4 의 원칙은 셋이다.

1. **제대로 짚으면 둘 다 걸린다.** 상대가 내 성향을 저지하고 있으면 −(a + d). 잘못 짚었으면 +(a + d). 많이 걸수록 이기면 크게 이기고 지면 크게 진다. 공격도 수비도 같다.
2. **아무도 안 건 특성은 건 쪽 것이다.** 상대가 그 특성에 없으면 +a, 내가 없으면 −d.
3. **2개 미만은 없는 것이다.** 상쇄 후 세기가 1 이면 그 특성은 없는 것으로 본다. 잔재는 세지 않는다.

쌓기의 평균 이득은 "상대가 그 특성을 비웠을 때" 에서 나온다. 규칙 3 때문에 상대가 특성을 비우는 경우가 38~58% 가 되어, 6개를 쌓은 성향의 기댓값(1.6~3.8)이 규칙 3 없이(0.3~2.7)보다 높다. 제대로 짚힘과 잘못 짚음은 대략 반반이라 서로 상쇄되므로, 쌓기는 확률보다 판돈을 키우는 선택이고 그래서 읽기 싸움이 살아 있다. 평가기로 재면 최대 쌓기가 2 에서 5 로 갈 때 공격 조합의 평균 value 는 40 에서 64 로, 상대에 따른 진폭은 28 에서 38 로 함께 커진다. 수비도 같은 모양이다.

줄 구조는 없앴다. 특성은 색(템포·조직·폭·공간)이다. **같은 특성의 두 성향은 같은 재료를 반대 방향으로 그린 아이콘**이라 두 장에 나란히 놓이면 서로 지우는 것이 보인다: 점유 = 공을 돌리는 원형 화살표 / 전환 = 앞으로 내달리는 겹화살, 측면 = 가운데서 바깥으로 벌리는 화살 / 중앙 = 바깥에서 가운데로 모으는 화살, 뒷공간 = 수비 라인을 넘기는 호 / 발밑 = 발 앞의 공으로 내려꽂는 화살, 패턴 = 패스 삼각형 / 개인 = 혼자 흔들며 뚫는 드리블. **수비 아이콘은 특성 색 방패 안에 노리는 공격 성향을 새긴 것**이고 이름은 코칭 용어다: 압박 / 내려서기(템포), 대인 / 지역 커버(조직), 측면 봉쇄 / 중앙 밀집(폭), 딥 라인 / 하이 라인(공간). "상대 방패 안의 성향이 내 성향과 같으면 카운터, 같은 색의 다른 성향이면 헛짚음" 이 전부다 (D-11). 이 문서의 표에서는 읽기 쉽게 수비 아이콘을 노리는 성향으로 "점유 저지" 처럼 적는다.

## 2. 카드에 있는 것

| 특성 | 공격 성향 | 수비 저지 아이콘 | 맡는 마커 |
|---|---|---|---|
| 템포 | 점유 / 전환 | 점유 저지 = 압박 / 전환 저지 = 내려서기 | ① 카운터 경계 |
| 조직 | 패턴 / 개인 | 패턴 저지 = 대인 / 개인 저지 = 지역 커버 | ② 소유 상실 경계 |
| 폭 | 측면 / 중앙 | 측면 저지 = 측면 봉쇄 / 중앙 저지 = 중앙 밀집 | ③ 전진 경계 |
| 공간 | 뒷공간 / 발밑 | 뒷공간 저지 = 딥 라인 / 발밑 저지 = 하이 라인 | ④ 찬스 경계 |

카드에는 아이콘만 있다(특성당 0~3, 카드당 총 3~6). 텍스트는 한 방·안전·끊기·지우개 4종이 4장에만 있다.

## 3. 판정 절차

1. 양쪽이 2장씩 낸다 (공개 순서는 D-8).
2. **세기**: 특성마다 두 장의 아이콘을 더한다. 같은 특성에 반대 성향이 함께 있으면 1:1 로 지우고, 지운 쌍마다 **혼선 −2** 를 그 특성 결과에 적는다. 남은 세기가 **2 미만이면 그 특성은 없는 것**이다.
3. **맞대기**: 특성마다 내 세기 a, 상대 세기 d.
   - 상대의 저지가 내 성향과 **같은 모양**이면 (막힘): **−(a + d)**
   - 상대의 저지가 같은 특성의 **다른 모양**이면 (잘못 짚음): **+(a + d)**
   - 상대가 그 특성에 없으면: **+a**. 내가 없으면: **−d**. 둘 다 없으면 0.
4. **마커 이동**: 트랙 20칸, 마커 기본 위치 2 / 8 / 14 / 18. 특성 결과 1점마다 3칸, 양수는 왼쪽. 특성은 자기 마커와 오른쪽 마커를 모두 옮긴다 (템포 ①②③④, 조직 ②③④, 폭 ③④, 공간 ④). 옮긴 뒤 왼쪽부터 ①②③④ 로 읽는다.
5. d20. ① 이하 카운터 / ② 소유 상실 / ③ 전진 / ④ 찬스 / 그 위 결정적 찬스.

예. 롱볼(전환 3, 뒷공간 2, 중앙 1) + 라인 브레이킹 런(뒷공간 2, 전환 2) = 전환 5, 뒷공간 4. 중앙 1 은 2 미만이라 없는 것.
- 상대가 하이 프레스 + 오프사이드 트랩 (점유 저지 4, 발밑 저지 5, 패턴 저지 1): 템포는 잘못 짚음 +9, 공간도 잘못 짚음 +9, 패턴 저지 1 은 없는 것. 마커가 전부 왼쪽 끝으로 가서 어떤 눈이 나와도 결정적 찬스다. 압박하고 라인을 올린 팀이 롱볼 한 방에 뚫린 장면.
- 상대가 로우 블록 + 딥 라인 (전환 저지 4, 뒷공간 저지 4, 개인 저지 1): 제대로 짚음 → 템포 −9, 공간 −8. 마커가 전부 오른쪽 끝으로 가서 무조건 카운터다. 내려선 팀에게 롱볼을 고집하면 뺏기고 역습을 맞는다.
- 상대가 로우 블록 + 지역 수비 (전환 저지 2, 뒷공간 저지 2, 중앙 저지 2, 개인 저지 2): 템포 −7, 공간 −6, 폭과 조직은 내가 없어 −2 씩.
- 상대가 하이 프레스 + 스위퍼 키퍼 (점유 저지 4, 발밑 저지 4, 패턴 저지 1): 템포 +9, 공간 +8. 패턴 저지 1 은 2 미만이라 조직은 0 이다.
- 공격을 티키타카(점유 3, 패턴 2, 발밑 1) + 롱볼로 섞으면 템포에서 점유 3 과 전환 3 이 전부 지워져 혼선 −6, 공간에서 발밑 1 과 뒷공간 1 이 지워져 혼선 −2, 남은 뒷공간 1 은 없는 것. 정체성 없는 조합은 이 −8 을 어디서도 못 메운다.

## 8. 카드마다 실제 축구의 무엇인가

이름은 감독과 해설이 실제로 쓰는 용어에서 가져왔고, 영어 이름은 그 용어의 통용 표기다. 아이콘은 5절 표가 원본이다. 2개 이상 있는 성향이 그 전술의 정의에서 나온 주 성향이고, 1개짜리는 균형을 위해 미리 정한 후보 안에서 배치기가 고른 보조 아이콘이다(혼자서는 2 미만이라 없는 것이고, 같은 성향의 다른 카드와 겹칠 때만 산다).

### 공격

| 카드 | 실제 축구에서 | 왜 그 성향인가 |
|---|---|---|
| A01 후방 빌드업 (Build-up from the back) | 골키퍼·센터백부터 짧은 패스로 전진하는 조직적 빌드업 | 공을 오래 소유한다(점유 3). 발밑으로 받는 것과 정해진 패스 경로는 보조(발밑·패턴). 하이 프레스에 잡히면 자기 진영에서 뺏긴다 |
| A02 티키타카 (Tiki-taka) | 짧은 패스를 반복해 상대를 끌어내고 공간을 만드는 점유 축구 | 점유의 극단(점유 3). 삼각형 패턴으로 움직이고(패턴) 발밑으로 받는다 |
| A03 롱볼 (Long ball) | 후방에서 전방으로 한 번에 보내는 직선적 공격 | 빌드업을 건너뛰는 전환(전환 3)과 뒷공간으로 떨어지는 공(뒷공간). 중앙 타겟은 보조 |
| A04 측면 오버로드 (Wide overload) | 한쪽 측면에 선수를 몰아 수적 우위를 만드는 것 | 측면에서 공을 돌리며(점유 3·측면) 우위를 만든다 |
| A05 스위칭 플레이 (Switch of play) | 긴 횡패스로 반대편 측면으로 전환하는 것 | 오버로드 뒤에 오는 반대편 공략. 측면과 점유 |
| A06 중거리 슛 (Long-range shot) | 박스 밖에서 때리는 슛 | 한 명이 때린다(개인) + 한 방. 중앙은 보조 |
| A07 템포 조절 (Game management) | 리드할 때 공을 돌리며 경기를 관리하는 것 | 위험을 지우는 점유 + 안전. 카운터를 맞지 않는 것이 목적이라 카운터 경계가 1 |
| A08 오버래핑 풀백 (Overlapping full-back) | 풀백이 윙어 바깥으로 올라가는 움직임 | 폭을 만드는 가장 단순한 카드(측면). 올라가는 타이밍은 전환이 보조 |
| A09 얼리 크로스 (Early cross) | 수비가 자리 잡기 전에 일찍 올리는 크로스 | 빠른 전환 뒤 측면에서 바로 올린다(측면·전환) |
| A10 컷백 (Cut-back) | 엔드라인까지 가서 뒤로 내주는 패스 | 측면 끝까지 간다(측면). 정해진 지점으로 내주고 발밑에서 때리는 것은 보조 |
| A11 하프스페이스 침투 (Half-space run) | 측면과 중앙 사이 공간으로 파고드는 것 | 중앙 쪽 공간(중앙 3)을 패턴 움직임으로 파고든다(패턴) |
| A12 스루패스 (Through ball) | 수비 라인 사이로 찔러 넣는 패스 | 중앙에서 뒷공간으로(중앙·뒷공간), 정해진 타이밍의 침투(패턴) |
| A13 인버티드 윙어 (Inverted winger) | 반대발 윙어가 안쪽으로 접어 들어오는 것 | 측면에서 시작해 중앙으로(중앙 3) 개인 돌파(개인) |
| A14 세컨볼 회수 (Second ball) | 롱볼·경합 뒤 떨어지는 공을 먼저 줍는 것 | 전환(전환 3)과 떨어지는 공이 가는 뒷공간(뒷공간). 롱볼·역습과 쌓인다 |
| A15 파울 유도 (Winning free kicks) | 드리블로 파울을 끌어내 프리킥·코너를 얻는 것 | 개인 돌파 시도가 세트피스로 이어진다(개인). 측면에서 자주 나온다(보조) |
| A16 역습 (Counter-attack) | 공을 얻자마자 빠르게 앞으로 가는 것 | 전환의 극단(전환 3) |
| A17 라인 브레이킹 런 (Run in behind) | 수비 라인 뒤로 달리는 침투 | 라인 뒤 공간으로(뒷공간·전환) + 한 방. 성공하면 1대1 이라 2d20 |
| A18 1대1 돌파 (Take-on) | 한 명이 수비 한 명을 제치는 것 | 개인 돌파(개인), 실제로 1대1 이 가장 많이 나오는 측면(측면) + 한 방 |
| A19 타겟맨 활용 (Hold-up play) | 큰 공격수가 공을 지키고 떨궈 주는 것 | 발밑으로 받아(발밑) 몸으로 지키는 개인 싸움(개인) |
| A20 폴스 나인 (False nine) | 공격수가 내려와 센터백을 끌어내는 것 | 발밑으로 받아(발밑) 패턴을 만든다(패턴) |

### 수비

수비 아이콘의 영어 이름은 코칭 용어에서 가져왔다: Press(압박) / Drop(내려서기), Man-oriented(대인) / Zonal cover(지역 커버), Show inside(안으로 몰기 = 측면 봉쇄) / Show outside(밖으로 몰기 = 중앙 밀집), Deep line(딥 라인) / High line(하이 라인).

| 카드 | 실제 축구에서 | 왜 그 저지인가 |
|---|---|---|
| D01 하이 프레스 (High press) | 상대 진영에서부터 압박하는 것 | 점유와 발밑으로 받는 것을 막는다(점유 저지·발밑 저지). 패턴 저지는 보조. 롱볼에 뚫린다 |
| D02 미들 블록 (Mid block) | 중원에 블록을 세우고 기다리는 것 | 중앙을 막고(중앙 저지) 개인 돌파를 지역으로 받고(개인 저지) 전환을 지연한다(전환 저지) |
| D03 로우 블록 (Low block) | 자기 진영 깊숙이 내려서는 것 | 전환할 공간이 없다(전환 저지). 뒷공간 저지는 보조. 점유에는 약하다 |
| D04 지역 수비 (Zonal marking) | 사람이 아니라 공간을 지키는 것 | 개인 돌파를 지역으로 받고(개인 저지) 중앙을 촘촘히 한다(중앙 저지). 패턴 움직임에는 약하다 |
| D05 맨마킹 (Man-marking) | 사람을 따라붙는 것 | 패턴 움직임을 사람으로 따라간다(패턴 저지). 측면 봉쇄가 붙는다(측면 저지). 개인 돌파에 약하다 |
| D06 컴팩트 (Compactness) | 라인 간격을 좁혀 중앙을 촘촘히 하는 것 | 중앙 공간이 없다(중앙 저지) + 지우개. 한 방(2d20)을 무효로 |
| D07 딥 라인 (Deep line) | 수비 라인을 내려 뒷공간을 없애는 것 | 뒷공간과 전환을 막는다(뒷공간 저지·전환 저지). 발밑으로 받는 것은 허용 |
| D08 게겐프레싱 (Counter-press) | 공을 잃은 직후 되찾는 압박 | 하이 프레스의 짧은 버전. 점유(점유 저지)와 패턴(패턴 저지)을 막는다 |
| D09 하이 라인 (High line) | 수비 라인을 올려 공간을 압축하는 것 | 발밑 공간이 없고(발밑 저지) 점유를 압박한다(점유 저지). 뒷공간 카드에 뚫린다 |
| D10 오프사이드 트랩 (Offside trap) | 라인을 맞춰 올려 침투를 걸어 내는 것 | 하이 라인의 극단(발밑 저지 3). 뒷공간을 열어 두는 도박 |
| D11 스위퍼 키퍼 (Sweeper-keeper) | 골키퍼가 나와 뒷공간을 정리하는 것 | 하이 라인의 보험이라 같은 방향의 저지(발밑 저지) |
| D12 박스 밀집 (Packing the box) | 페널티 박스 안에 몸을 던지는 것 | 뒷공간과 중앙을 몸으로 막는다(뒷공간 저지·중앙 저지). 측면과 중거리는 허용 |
| D13 5백 (Back five) | 센터백 3명과 윙백으로 폭을 막는 것 | 폭을 막는 가장 직접적인 카드(측면 저지) |
| D14 더블 피봇 (Double pivot) | 수비형 미드필더 둘이 중앙을 잠그는 것 | 중앙을 막는다(중앙 저지). 개인 돌파 커버는 보조 |
| D15 측면 더블팀 (Doubling up wide) | 윙어를 바깥으로 몰고 둘이 막는 것 | 측면 오버로드·스위칭에 대한 답(측면 저지·패턴 저지) |
| D16 압박 트리거 (Pressing trigger) | 백패스·횡패스 순간에만 달려드는 것 | 점유하는 팀의 느슨한 패스를 노린다(점유 저지 3) |
| D17 전술적 파울 (Tactical foul) | 위험해지기 전에 파울로 끊는 것 | 패턴 움직임을 몸으로 끊는다(패턴 저지) + 끊기. 결정적 찬스를 주지 않는다 |
| D18 역습 세팅 (Sit and counter) | 뒤에 남았다가 뺏는 즉시 달리는 것 | 상대의 전환을 받아 되받아친다(전환 저지 3) |
| D19 슛 스토퍼 (Shot-stopper) | 골키퍼가 라인을 지키며 슛을 막는 것 | 뒷공간으로 오는 공을 골키퍼가 처리한다(뒷공간 저지 3) |
| D20 세트피스 수비 (Set-piece defending) | 코너·프리킥에서 지역과 사람을 섞어 막는 것 | 파울 유도·1대1의 결과인 세트피스에 대한 답(개인 저지). 뒷공간 저지는 보조 |

## 9. 읽는 법과 설계 메모

- 상위 조합은 같은 성향을 두 장에 쌓은 조합이다. 쌓기의 이득이 공식에서 직접 나온다(+a 는 빠지지 않는다). 하위 조합은 반대 성향이 섞여 혼선을 먹는 조합이다.
- 쌓기의 이득은 판돈이지 확률이 아니다. 기댓값은 상대가 특성을 비웠을 때에서만 나오고(38~58%), 제대로 짚힘과 잘못 짚음은 반반이다. 확률까지 올리고 싶으면 평가기의 FORMULA=C (잘못 짚으면 +(2a+d), 제대로 짚히면 −(a+2d)) 로 바로 비교할 수 있다.
- 균형은 아이콘 배치만으로 맞췄다. 최적화는 카드마다 미리 정한 보조 성향 후보 안에서만 0~2개를 움직였고 주 성향은 2~3 으로 유지했다.
- 검증하지 않은 것: 사람이 실제로 고르는 조합, 라운드 연결과 득점, 공개 순서에서의 읽기 싸움.
