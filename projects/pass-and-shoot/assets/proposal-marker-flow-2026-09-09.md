# 마커 2개 이동과 5가지 결과의 경기 흐름 (2026-09-09)

**상태: D-12 로 확정(3절의 슈팅 굴림·전진 단계 안은 폐기, 공유 위치 트랙으로 대체). ** 원래 상태: 제안. 2026-09-09 의 지적 세 가지(특성 간 마커 무게 불균형, 특수 규칙 확장, 맞대기 공식 −d/+a)와 "특성마다 마커 2개를 옮기고 닿으면 밀어낸다" 는 제안을 받아 정리했다. 확정되면 D-12 로 기록하고 덱 v5 문서로 잇는다. 수치는 `playtests/deck-v5-eval.js` 로 재현된다.

## 0. 한 라운드의 판정 (전체 흐름)

1. 양쪽 2장. 특성(색)마다 아이콘을 더하고 반대 성향은 1:1 로 지운다. 지운 쌍마다 혼선 −2. 남은 세기가 2 미만이면 없는 것.
2. **맞대기**: 특성마다 내 세기 a, 상대 세기 d. 상대 방패가 내 성향을 노리고 있거나 내가 그 특성이 없으면 **−d**. 상대 방패가 다른 성향을 노리고 있거나 상대가 그 특성이 없으면 **+a**. 둘 다 없으면 0. (읽기에서 이긴 쪽이 자기 판돈을 받는다.)
3. **마커 이동**: 특성마다 마커 2개를 맡는다(1절). 마커는 자기를 맡은 두 특성의 결과를 더한 만큼 옮긴다(1점 = N칸, 양수는 왼쪽). 많이 움직이는 마커부터 옮기고, 아직 안 옮긴 마커에 닿으면 밀어내고, 이미 옮긴 마커에 닿으면 거기서 멈춘다.
4. **특수 규칙**으로 마커 최종 위치를 조정한다(2절): 안전, 끊기, 되찾기, 선방.
5. d20 (한 방·덫·세컨볼은 이 굴림을 바꾼다). 마커 ①②③④ 로 다섯 밴드 중 하나가 나온다(3절).

## 1. 마커 배분: 특성마다 2개, 순환

| 특성 | 맡는 마커 | 개연성 |
|---|---|---|
| 템포 (점유 / 전환) | ① 카운터, ② 소유 상실 | 템포 싸움에서 지면 공을 잃고 역습을 맞는다. 이기면 공을 잃지 않는다 |
| 조직 (패턴 / 개인) | ② 소유 상실, ③ 전진 | 조직 싸움은 수비 블록을 통과하느냐다. 이기면 전진, 지면 막혀서 공을 잃는다 |
| 폭 (측면 / 중앙) | ③ 전진, ④ 찬스 | 폭 싸움은 박스에 어떻게 닿느냐다. 이기면 찬스, 지면 전진에서 멈춘다 |
| 공간 (뒷공간 / 발밑) | ④ 찬스, ① 카운터 | 공간 싸움은 하이 리스크 하이 리턴이다. 이기면 결정적 찬스, 지면 오프사이드·걷어내기로 뒤가 열려 역습을 맞는다 |

마커마다 특성 둘이 걸린다(①: 템포·공간, ②: 템포·조직, ③: 조직·폭, ④: 폭·공간). 그래서 마커 하나의 이동량은 "맡은 두 특성 결과의 합" 이다.

대안으로 공간이 ③④ 를 맡는 배분(폭과 같은 마커)도 재 봤다. 공간에 카운터 위험이 사라져 개연성은 얌전해지지만 마커 ①이 템포 혼자 것이 되어 균형이 조금 나빠진다(아래 표). 어느 쪽이든 규칙 문장은 같다.

### 순서대로 옮기면 안 되는 이유

"1번 특성부터 4번 특성까지 차례로 옮기고 닿으면 밀어낸다" 를 그대로 재면 **마지막에 옮기는 특성이 앞 특성들이 옮긴 마커를 밀어내서 지배한다.** 특성 1점의 가치(모든 매치업에서 그 특성 결과를 1 올렸을 때 기대값 변화의 평균):

| 방식 | 템포 | 조직 | 폭 | 공간 | 최대/최소 |
|---|---|---|---|---|---|
| v4 (자기+오른쪽 마커 전부, 3칸) | 4.4 | 3.3 | 2.1 | 1.0 | 4.5배 |
| 2개씩, 템포→조직→폭→공간 순서로 밀기 | 1.3 | 2.3 | 4.0 | 7.5 | 5.7배 |
| 2개씩, 공간→폭→조직→템포 순서 (24가지 중 가장 고른 순서) | 3.8 | 3.4 | 2.7 | 1.6 | 2.4배 |
| **2개씩, 합쳐서 한 번에 (많이 움직이는 마커부터)** | **3.0** | **3.7** | **4.7** | **4.4** | **1.6배** |
| 위와 같되 공간이 ③④ | 3.1 | 3.6 | 4.3 | 4.3 | 1.4배 |

순서를 없애고 마커마다 두 특성의 결과를 합쳐서 한 번에 옮기면 어느 특성도 지배하지 못한다. 그래서 3항의 규칙은 "특성 순서" 가 아니라 "마커 순서(많이 움직이는 것부터)" 다. 플레이어 입장에서는 특성 4개의 결과를 적고 마커마다 둘씩 더해서 옮기면 된다.

### 밀어내기의 정확한 뜻

- 마커는 0~20 칸 위에 있고 서로 지나칠 수 없다. 같은 칸에 겹칠 수는 있다(그 사이 밴드가 비는 것).
- 옮기는 마커가 아직 안 옮긴 마커에 닿으면 그 마커를 같이 밀고 간다. 밀린 마커가 또 다른 안 옮긴 마커에 닿으면 그것도 민다.
- 옮기는 마커가 이미 옮긴 마커에 닿으면 거기서 멈춘다(먼저 많이 움직인 마커가 이긴다).
- 0 과 20 은 벽이다.

## 2. 특수 규칙 (텍스트 효과 9종, 카드 20장)

마커 조정 4종은 3항 뒤에 적용한다. 순서: 되찾기 → 선방 → 끊기 → 안전 (안전이 마지막이라 되찾기보다 우선한다).

| 효과 | 규칙 | 종류 | 카드 |
|---|---|---|---|
| 안전 | ① 을 1 로 (1 보다 왼쪽이면 그대로) | 마커 | 템포 조절, 파울 유도 |
| 끊기 | ④ 를 20 으로 (결정적 찬스 없음) | 마커 | 전술적 파울 |
| 되찾기 | ① 을 ② 위치로 (소유 상실은 카운터) | 마커 | 게겐프레싱 |
| 선방 | ③ 을 ④ 위치로 (찬스는 전진) | 마커 | 슛 스토퍼, 박스 밀집 |
| 한 방 | 2d20 중 큰 값 | 주사위 | 중거리 슛, 1대1 돌파, 라인 브레이킹 런, 인버티드 윙어 |
| 덫 | 2d20 중 작은 값 | 주사위 | 오프사이드 트랩, 압박 트리거 |
| 지우개 | 상대 한 방 무효 | 주사위 | 컴팩트 |
| 침착 | 상대 덫 무효 | 주사위 | 티키타카 |
| 세컨볼 | 소유 상실이면 한 번 다시 굴린다 | 주사위 | 세컨볼 회수 |
| 무시 | 상대의 특정 아이콘 1개를 없는 것으로 (1항 전에) | 세기 | 폴스 나인(대인), 스위칭 플레이(측면 봉쇄), 스위퍼 키퍼(뒷공간), 5백(측면), 더블 피봇(중앙) |

한 방과 덫이 동시에 살아 있으면 1d20 이다.

## 3. 다섯 결과와 경기 흐름

트랙에는 마커 4개와 별도로 **전진 단계 표시**(0 / 1 / 2)가 있다. 라운드 시작 마커는 기본 2 / 8 / 14 / 18 에서 단계마다 3칸 왼쪽이다(1단계 0/5/11/15, 2단계 0/2/8/12). 이것이 존 트랙(Q-28)이다: 0 = 자기 진영, 1 = 중원, 2 = 상대 진영.

| 굴림 | 결과 | 실제 축구 | 다음 라운드 |
|---|---|---|---|
| ① 이하 | 카운터 | 위험한 곳에서 뺏겨 역습을 맞는다 | 공격권 교대. 상대는 **2단계**에서 시작(즉시 상대 진영) |
| ① 초과 ② 이하 | 소유 상실 | 공을 잃었지만 수비는 자리를 잡았다 | 공격권 교대. 상대는 0단계 |
| ② 초과 ③ 이하 | 전진 | 공을 더 높은 지역으로 옮겼다 | 같은 공격자. 단계 +1 (최대 2) |
| ③ 초과 ④ 이하 | 찬스 | 슈팅 상황 | 슈팅 굴림 d20, **14 이상 골**. 골이면 킥오프(실점 팀 공격, 0단계). 아니면 골킥(상대 공격, 0단계) |
| ④ 초과 | 결정적 찬스 | 골키퍼와 1대1, 빈 골대 | 슈팅 굴림 d20, **8 이상 골**. 뒤는 찬스와 같다 |

- 경기: 전반 N 라운드, 후반 N 라운드, 후반 킥오프는 전반 킥오프의 반대 팀. N 의 가안은 8 (Q-8). 동점 처리는 Q-9.
- 기대 골: 카드를 무작위로 낸다고 가정하면 라운드당 결정적 찬스 26%, 찬스 13% 가 나온다(추천안, 0단계). 슈팅 굴림을 위처럼 두면 라운드당 기대 골 0.65×0.26 + 0.35×0.13 ≈ 0.21, 16 라운드면 경기당 3.4 골이다. 사람이 읽기 싸움을 하면 이보다 낮아진다. 슈팅 기준값 14/8 과 N 은 플레이테스트로 정할 수치다(Q-31).
- 결정적 찬스를 "무조건 골" 로 두는 안도 가능하다. 그러면 경기당 5~6 골이라 N 을 5~6 으로 줄여야 한다. 슈팅 굴림이 하나 더 있는 편이 "찬스를 놓치는" 축구의 감정에 가깝다고 봐서 위 안을 밀었다.

## 4. 예 (추천안 아이콘)

롱볼(전환 2, 뒷공간 2, 중앙 2) + 라인 브레이킹 런(뒷공간 3, 전환 2, 개인 1, 한 방) = 전환 4, 뒷공간 5, 중앙 2. 개인 1 은 없는 것.

상대가 하이 프레스(압박 3, 하이 라인 2, 대인 1) + 오프사이드 트랩(하이 라인 2, 압박 1, 덫): 압박 4, 하이 라인 4. 대인 1 은 없는 것.
- 템포: 상대 방패는 점유를 노리는데 나는 전환 → 헛짚음 **+4**. 공간: 상대는 발밑을 노리는데 나는 뒷공간 → **+5**. 폭: 나만 있음 **+2**. 조직: 둘 다 없음 0.
- 마커 이동(1점 = 3칸): ① = 템포+공간 = 9점 → 27칸 왼쪽, ② = 템포+조직 = 4점 → 12칸, ③ = 조직+폭 = 2점 → 6칸, ④ = 폭+공간 = 7점 → 21칸. 많이 움직이는 ①부터: ① 2→0. ④ 18→0 이 되면서 아직 안 옮긴 ②③ 을 0 으로 민다. 결과 0/0/0/0.
- 어떤 눈이 나와도 결정적 찬스. 압박하고 라인을 올린 팀이 롱볼 한 방에 뚫린 장면이다. (한 방과 덫이 동시에 살아 1d20 이지만 여기서는 상관없다.)

상대가 로우 블록(내려서기 2, 딥 라인 1) + 딥 라인(딥 라인 2, 지역 커버 2, 내려서기 1): 내려서기 3, 딥 라인 3, 지역 커버 2.
- 템포: 제대로 짚힘 **−3**. 공간: 제대로 짚힘 **−3**. 폭: 나만 있음 **+2**. 조직: 상대만 있음 **−2**.
- ① = −6점 → 18칸 오른쪽, ② = −5점 → 15칸, ③ = 0, ④ = −1점 → 3칸. ①부터: ① 2→20 이 되면서 ②③④ 를 전부 20 으로 민다. 결과 20/20/20/20: 무조건 카운터. 내려선 팀에게 롱볼을 고집하면 뺏기고 역습을 맞는다. 폭에서 +2 를 땄어도 템포·공간에서 진 것을 못 막는다.
